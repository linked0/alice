## en
- **Personas: if a persona NFT ever gets autonomous, agent-driven behavior, write its behavior constraints as a reviewable constitution document rather than tuning only by example.** This makes the persona's values auditable.
- **Rabbit: model session-key mandates on the critique-and-revise loop.** Check a proposed agent action against the mandate text before executing it, not only the signature that authorized the mandate.

## ko
- **Personas: 페르소나 NFT가 자율적인 에이전트 행동을 갖게 된다면, 예시로만 조정하는 대신 행동 제약을 검토 가능한 헌법 문서로 작성한다.** 페르소나의 가치판단을 감사 가능하게 만든다.
- **Rabbit: 세션 키 mandate를 비판-수정 루프를 본떠 설계한다.** mandate를 승인한 서명만 확인하는 것이 아니라, 실행 전에 제안된 에이전트 행동을 mandate 문서 자체에 대조해 검사한다.
