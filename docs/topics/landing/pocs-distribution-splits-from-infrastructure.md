## en
- **Wallet: run the conflict audit on jayverse-wallet itself.** List every default (recommended chain = Devnet, default bridge, default swap = the mini-AMM) and ask whether an independent wallet would pick the same default; where the answer is no, document it rather than hide it.
- **Bridge/Token/Devnet: since one company owns all four, disclosure replaces separation.** Label Devnet as the house chain in the wallet UI instead of presenting it as a neutral default, since structural separation isn't an option here.
- **Rabbit: require default-disclosure in the portal.** Before Rabbit recommends a route (bridge, swap, chain), the interface should flag when the recommended default is Jayverse's own infrastructure.

## ko
- **Wallet: jayverse-wallet 자체에 충돌 감사를 실행한다.** 모든 기본값(추천 체인 = Devnet, 기본 브리지, 기본 스왑 = 미니 AMM)을 나열하고 독립적인 지갑이라면 같은 기본값을 택했을지 묻는다. 답이 아니오라면 숨기지 말고 문서화한다.
- **Bridge/Token/Devnet: 네 서비스를 한 회사가 소유하므로 분리 대신 공개를 택한다.** Devnet을 중립적 기본값처럼 보여주지 말고 지갑 UI에서 하우스 체인이라고 표시한다. 여기서는 구조적 분리가 선택지가 아니기 때문이다.
- **Rabbit: 포털에서 기본값 공개를 필수화한다.** Rabbit이 경로(브리지, 스왑, 체인)를 추천하기 전에, 추천된 기본값이 Jayverse 자체 인프라일 때는 인터페이스가 이를 표시해야 한다.
