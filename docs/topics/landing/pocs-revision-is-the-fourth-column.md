## en
- **Number: store value@date alongside current@date for every distributed reading.** Any macro or indicator figure Number publishes should keep the value as first printed and the value as later revised, each dated, so downstream analysis is never built unknowingly on a since-revised draft.
- **Auditor: require a revision note in the methodology before a decision cites an indicator.** For any signal feeding a Jayverse decision, the methodology should say whether the source revises and which read — first-print or revised — was actually used.

## ko
- **Number: 배포하는 모든 리딩에 value@date와 current@date를 함께 저장한다.** Number가 공개하는 거시·지표 수치는 처음 발표된 값과 이후 수정된 값을 각각 날짜와 함께 보관해, 후속 분석이 이미 수정된 초안 위에 무심코 쌓이지 않게 한다.
- **Auditor: 지표를 인용한 결정 전에 방법론에 수정 이력 노트를 요구한다.** Jayverse의 결정에 들어가는 모든 신호는, 출처가 수정되는지, 실제로 사용한 값이 초판인지 수정판인지를 방법론에 명시해야 한다.
