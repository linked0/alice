## en
- **Game: measure the rig, not the mesh, before generating any Unity street character with a tool like this.** Clean topology, sensible joint placement and artifact-free skin weights are the acceptance test; a pretty mesh on a bad rig still costs the manual retopology time this tool claims to remove.
- **Personas: decide up front whether persona-NFT art needs to be animatable.** If the persona market ever wants moving avatars rather than static images, a T-pose-plus-rig pipeline is the shape to evaluate against, tested on the same rig-quality criteria as the Game asset.
- **OFA: flag the naming collision in any doc that mentions "Atlas."** OFA's own design draws on FastLane's Atlas (execution abstraction); since this is an unrelated text-to-3D product with the same name, Jayverse notes should always say which Atlas they mean.

## ko
- **Game: 이런 도구로 유니티 거리 캐릭터를 생성하기 전에 메시가 아니라 리그를 측정한다.** 깔끔한 토폴로지, 합리적인 관절 배치, 아티팩트 없는 스킨 웨이트가 수용 기준이다. 리그가 나쁜 예쁜 메시는 여전히 이 도구가 없애준다는 수작업 리토폴로지 시간을 그대로 든다.
- **Personas: 페르소나 NFT 아트가 애니메이션이 필요한지 미리 결정한다.** 페르소나 마켓이 언젠가 정적 이미지가 아니라 움직이는 아바타를 원한다면, T-포즈+리그 파이프라인이 평가 대상이며 Game 에셋과 같은 리그 품질 기준으로 테스트한다.
- **OFA: "Atlas"를 언급하는 모든 문서에 이름 충돌을 명시한다.** OFA 자체 설계는 FastLane의 Atlas(실행 추상화)를 참고한다. 이것은 이름만 같은 무관한 text-to-3D 제품이므로, Jayverse 노트는 항상 어느 Atlas를 말하는지 밝힌다.
