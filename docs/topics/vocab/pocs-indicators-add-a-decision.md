| Expression | 뜻 · 쓰이는 자리 |
|---|---|
| low-pass filter | 저주파 통과 필터(급격한 변동을 걸러 완만하게 만듦) · 이동평균의 성질을 설명할 때. "A moving average is a low-pass filter" |
| buy back | (지연 등을) 다시 벌어 상쇄하다 · 한 지표가 다른 지표의 단점을 보완할 때. "buys back some of that lag" |
| pay for X in Y | X의 대가를 Y로 치르다 · 이득과 대가가 맞바뀔 때. "pays for it in noise" |
| readout | (측정값의) 판독 결과 · 지표가 보여주는 것이 정확히 무엇인지 말할 때. "a volatility readout and nothing else" |
| Schelling point | 셸링 포인트(다들 암묵적으로 모이는 지점) · 유명 레벨이 예측이 아니라 조정 지점임을 말할 때. "closer to a Schelling point than to a forecast" |
| cut both ways | 장단이 함께 있다, 양날의 검이다 · 한 사실이 좋게도 나쁘게도 작용할 때. "That cuts both ways" |
| run through | (많이 몰려서) 뚫려버리다 · 모두가 보는 레벨이 역이용당할 때. "a level everyone can be run through" |
| out loud | 소리 내어, 명시적으로 · 함정을 숨기지 않고 드러내 말할 때. "Name the trap out loud before starting" |
| out-of-sample | 표본 밖(검증에 쓰지 않은) 구간의 · 백테스트 방법론을 말할 때. "Test out-of-sample, on bars you have not read" |
| corollary | 당연한 귀결, 따름정리 · 앞 주장에서 자연히 따라 나오는 결론을 말할 때. "The corollary is the part worth keeping" |
