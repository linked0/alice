|---|---|
| posterior distribution | 사후분포 · 사전 믿음과 관측 데이터를 결합해 얻은 갱신된 확률분포 · "belief-plus-evidence into a posterior distribution" |
| survive weak data | 빈약한 데이터에도 살아남다 · 강한 사전 믿음이 약한 증거로는 잘 바뀌지 않는다는 뜻 · "a confident prior can survive weak data" |
| point estimate | 점추정치 · 불확실성을 감춘 채 하나의 숫자로만 제시된 값 · "instead of hiding it in a point estimate" |

| opinionated prior | (강한 주장이 담긴) 편향된 사전분포 · 분석자의 믿음이 강하게 반영된 사전분포 · "versus an opinionated prior" |
