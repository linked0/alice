| control authority | 제어 권한(얼마나 자세를 바꿀 수 있는가) · 속도가 0이면 0이 되는 양. "Control authority is a function of relative motion" |
| to deflect the helm / hard over | 타를 꺾다 / 끝까지 꺾은 상태 · 움직이지 않는 배에서 무의미함을 보일 때 |

| environment design | 환경 설계 · 의지를 강화하는 대신 빠져나갈 수 없는 환경에 들어가는 것 |
| to deflect (a title) | (호칭을) 손사래 치며 피하다 · "작가님" 호칭 앞의 반사적 반응. "The reflex is to deflect" |
| to take X as an instruction | X를 지시문으로 받다 · 호칭을 자격이 아니라 명령으로 해석한 전환. "took the title as an instruction" |
| unearned | 아직 얻지 않은 · 자격 없이 붙은 것처럼 느껴지는. "an identity you have not earned yet" |

| aspirational | 낭만적·이상적인 · 여기서는 "출발점은 낭만적이지 않다"의 반대말로. "The starting point is not aspirational" |
