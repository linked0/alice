| Expression | 뜻 · 쓰이는 자리 |
|---|---|
| survive (a crash) | 충돌 등에도 살아남다, 버텨내다 · 시스템이 장애 후에도 상태를 유지할 때. "survive the machine dying" |
| hand-rolled | 직접 손으로 짠, 자체 제작한 · 기성 도구 대신 직접 만든 해법. "what they build is a hand-rolled state machine" |
| breaks it silently | 조용히 망가뜨리다, 티 안 나게 고장내다 · 오류가 눈에 띄지 않게 발생할 때. "breaks it silently, on recovery, long after" |
| the seam | 이음매, 경계 지점 · 두 성질이 나뉘는 지점을 비유할 때. "The seam: everything non-deterministic moves into an activity" |
| repriced rather than reinvented | 재발명이 아니라 재평가된 · 기존 기술이 새 용도로 값어치를 다시 인정받을 때. "the old primitive gets repriced rather than reinvented" |
| idempotent under retry | 재시도해도 결과가 같은 성질 · 같은 요청을 여러 번 보내도 안전할 때. "on-chain transactions must be idempotent under retry" |
| in flight | 진행 중인, 처리 중인 · 아직 끝나지 않은 작업이나 실행을 가리킬 때. "deploying new workflow code while runs are in flight" |
| quietly becomes | 슬그머니 ~이 되어버리다 · 의도치 않게 문제로 바뀔 때. "quietly becomes double-spending" |
| fight it for a month | 한 달 내내 애먹다, 씨름하다 · 이해 부족으로 계속 고생할 때. "will fight it for a month" |
| worth noticing beyond | ~을 넘어서도 주목할 가치가 있는 · 한 사례를 넘어 일반화할 때. "That is worth noticing beyond this one vendor" |
