| Expression | 뜻 · 쓰이는 자리 |
|---|---|
| dead on arrival | 나오자마자 이미 실패한 · 시작 전부터 승산이 없다는 강한 표현 · "a single-issuer bank coin is dead on arrival" |
| governance bill coming due | 쌓여있던 거버넌스 비용이 청구서로 돌아오다 · 회원이 많을수록 의사결정 비용이 커진다는 비유 · "the governance bill coming due" |
| out-run | ~을 앞지르다, 추월하다 · 경쟁에서 속도로 이기는 것을 말할 때 · "the banks out-run the incumbents" |
| re-fence the field | 경쟁의 장을 다시 울타리 치다 · 규제가 새 참가자에게 유리하게 판을 재편한다는 비유 · "GENIUS and MiCA re-fence the field" |
| bolt onto | (기존 것에) 덧붙이다, 이어붙이다 · 새 시스템을 낡은 인프라 위에 얹을 때 · "bolt it onto correspondent rails that close" |
| wearing a ...'s name | ~라는 이름만 달고 있다 · 실질은 다른데 겉모습만 그렇게 불린다는 뜻 · "wearing a stablecoin's name" |
| where applicable | 해당되는 경우에 한해 · 관할권마다 규정이 다를 수 있음을 못박는 법률 문구 · "Read "where applicable" twice: twenty-one institutions from Tokyo" |
| churn | (회원·고객의) 이탈, 이탈률 · 컨소시엄이 참여자를 계속 잃는 현상 · "Consortium products fail by churn, not by launch" |
| on equal terms | 동등한 조건으로 · 경쟁자가 같은 규칙 아래 경쟁할 수 없다는 문맥 · "cannot enter on equal terms" |
| concedes | (마지못해) 인정하다, 시인하다 · 문구 하나가 큰 불확실성을 인정한다는 뜻 · ""Where applicable" concedes the answer differs by geography" |
| GENIUS | 미국 스테이블코인 규제법(GENIUS Act) · 발행자 요건·감독 체계를 정한 연방법, "payment stablecoin" 분류의 근거. "a GENIUS payment stablecoin" |
| MiCA | EU 암호자산시장 규제(Markets in Crypto-Assets) · 스테이블코인을 EMT 등으로 분류해 감독하는 EU 법. "a MiCA EMT?" |
| EMT | 전자화폐토큰(E-Money Token) · MiCA상 법정화폐 1:1 연동 토큰에 적용되는 분류 카테고리. "a GENIUS payment stablecoin, or a MiCA EMT" |
| SWIFT | 국제은행간통신협회(Society for Worldwide Interbank Financial Telecommunication) · 은행들이 공유하는 대표적 결제 메시징 네트워크. "card networks, Zelle, SWIFT itself" |
| Fnality | 은행 컨소시엄이 소유한 도매결제 네트워크 · 유사 컨소시엄 선례로 인용, 느린 속도의 원인이 전원합의 구조임을 보여주는 사례. "bank consortium, wholesale settlement" |
