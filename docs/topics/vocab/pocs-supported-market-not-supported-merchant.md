| Expression | 뜻 · 쓰이는 자리 |
|---|---|
| Merchant of Record (MoR) | 법적 판매자 — 결제 대행이 아니라 **판매 주체 자체**를 맡는 서비스 |
| merchant country | 가맹 국가 — PSP가 **계정 개설을 받아주는 관할.** 시장 지원과 다름 |
| a supported market | 지원되는 시장 — 그 나라 **구매자에게 청구할 수 있다**는 뜻일 뿐 |
| the seller of record | 기록상의 판매자 — 인보이스와 세금이 귀속되는 주체 |
| PSP (payment service provider) | 결제 서비스 제공자 — 처리만 하고 판매자는 당신 |
| to remit tax | 세금을 납부하다 — 걷는 것(collect)과 내는 것(remit)은 다른 동작 |
| sales-tax nexus | 판매세 넥서스 — 미국에서 어느 주에 납세 의무가 생기는가의 기준 |
| zero-rated vs exempt | 영세율 대 면세 — **영세율은 환급이 되고 면세는 안 된다.** 수출 용역에 중요 |
| a chargeback | 차지백 — 카드 소지자가 결제를 되돌리는 것. MoR이 책임을 진다 |
| a prohibited-business list | 금지 업종 목록 — **만들기 전에 읽어야 하는 문서** |
| a refused category | 거부 카테고리 — 스레드 작성자의 맥 클리너가 걸린 자리 |
| an existential risk to the account | 계정의 존폐가 걸린 위험 — 비용 항목과 구분됨 |
| all-in (pricing) | 올인 요율 — 추가 요금이 붙지 않는다는 뜻 |
| a surcharge | 추가 요금 — 표면 요율이 실제를 낮춰 보이게 만드는 것 |
| to amortise a fixed cost | 고정 비용을 분산 상각하다 — 대형 사업자만 할 수 있는 일 |
| a moat | 해자 — 경쟁자를 막는 구조적 장벽 |
| regulatory capture | 규제 포획 — 규제가 피규제자의 이익에 봉사하게 되는 현상 |
| an incumbent | 기존 사업자 — 진입자(entrant)의 반대 |
| a constituency | (이익을 대변하는) 지지 세력 — 규칙을 지키려는 쪽이 누구인가 |
| to borrow someone else's jurisdiction | 남의 관할을 빌리다 — 싱가포르 법인, MoR 둘 다 이것 |
| the binding constraint is a legal category | 구속 조건이 법적 범주다 — #74와 공유하는 형태 |
| to go stale (of a claim) | (주장이) 낡다 — 사실이 바뀌어 더는 맞지 않게 되는 것 |
| to conflate | 뭉개다 — 다른 둘을 하나로 다룰 때 |
