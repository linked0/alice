| Expression | 뜻 · 쓰이는 자리 |
|---|---|
| does not transfer | 그대로 적용되지 않는다, 전이되지 않는다 · 한 상황에서 배운 것이 다른 상황엔 안 맞을 때. "a list of attacks does not transfer" |
| blast radius | 피해 반경 · 침해된 요소가 실제로 닿을 수 있는 범위를 가리킬 때. "the blast radius of an authorized component" |
| come apart | 어긋나다, 분리되다 · 원래 같아야 할 두 개념이 갈라질 때. "where authorized and safe come apart" |
| land on | (어떤 항목이) 들어맞다, 해당하다 · 점검 목록이 실제 지점과 맞아떨어질 때. "an entry either lands on a crossing you drew" |
| falsifiable | 반증 가능한 · 틀렸다고 지적할 수 있는 형태의 주장·모델을 말할 때. "a boundary diagram is falsifiable" |
| syllabus | (비유) 외워야 할 교본, 학습 목록 · 그대로 암기하듯 다루는 태도를 비판할 때. "attack lists are its output rather than its curriculum" |
| on purpose | 일부러, 의도적으로 · 우연이 아니라 의도된 결정임을 강조할 때. "the module was deployed on purpose" |
| reflex (controls) | 반사적으로 나오는, 관성적인 (통제) · 깊이 생각하지 않고 습관처럼 적용하는 보안 조치. "the reflex controls both answer the wrong question" |
| churn | (용어·유행의) 잦은 교체 · 시간이 지나며 이름이나 트렌드가 계속 바뀌는 상황. "survive the churn that retires specific vulnerability names" |
| coverage test | 커버리지 점검, 빠짐없이 확인하는 테스트 · 목록을 검증 도구로 쓸 때. "use it as a coverage test on the diagram" |
