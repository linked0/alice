| Expression | 뜻 · 쓰이는 자리 |
|---|---|
| **a 47-place gap** | 47계단 격차. 순위 차이를 말하는 가장 자연스러운 형태 (a 3-point gap, a two-year gap) |
| **a founder's canon vs. a reader's canon** | 창시자의 정전 대 독자의 정전. A's X vs. B's X 로 두 관점을 대비하는 틀 |
| **state it plainly** | 분명하게 말하다. plainly = 꾸밈없이, 에두르지 않고 |
| **the recency effect** | 최신 편향. 설문·기억 연구의 용어인데 일상 분석에도 그대로 씀 |
| **back catalogue** | 구작 목록. 음반·영화사의 과거 작품 전체 |
| **licenses calling X Y** | X를 Y라고 부르는 것을 정당화한다. license = 근거를 준다 (동사) |
| **reported rather than silently dropped** | 조용히 지우지 않고 보고함. 데이터 결함을 다루는 태도를 밝히는 정형구 |
| **a paste artifact** | 붙여넣기 과정에서 섞여 들어온 오염. artifact = 인공적으로 생긴 잡음 |
| **treat X with some caution** | X를 다소 조심해서 다루다. 부정하지 않으면서 신뢰를 낮출 때 |
| **the near-miss** | 간발로 떨어진 것 |
| **invisible as an artwork** | 작품으로는 보이지 않는. as ~ = ~로서 |
| **blind spot** | 맹점. 개인·조직·분야 전부에 쓰임 |
