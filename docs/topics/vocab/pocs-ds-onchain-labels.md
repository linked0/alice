| inherit | (성질을) 물려받다 · 하위 지표가 상위 데이터의 정확도와 오류를 그대로 이어받을 때. "every on-chain metric downstream inherits the accuracy" |
| propagate | 전파되다, 퍼져나가다 · 작은 오류가 뒤로 갈수록 점점 더 큰 결론의 오류로 번질 때. "how a wrong label propagates into a wrong conclusion" |

| heuristics | 휴리스틱, 경험적 판단 규칙 · 정확한 증명 대신 경험 규칙으로 분류할 때. "funding source, interaction graph" |
