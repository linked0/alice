| Expression | 뜻 · 쓰이는 자리 |
|---|---|
| settlement leg | 정산 구간 · 결제 흐름을 구간(leg)으로 나눠 부를 때. "the leg nobody sees" |
| inter-institution | 기관 간의 · 소비자가 아니라 발행사·네트워크·매입사 사이. "the settlement process between financial institutions" |
| to go live | 실제 운영에 들어가다 · 시범을 넘어 가동됨. "SoFi Becomes First National Bank to Go Live" |
| in production | 실제 운영 환경에서 · 실험(experiment)의 반대말로 쓰임 |
| annualised volume | 연환산 거래액 · 일부 기간 실적을 1년으로 환산한 값. 실현액이 아님 |
| gross vs net | 총액 대 순액 · 카드 정산은 상계 후 순액만 움직인다는 이 카드의 핵심 지적 |
| to net (obligations) | 채무를 상계하다 · 양방향 채무를 차감해 순포지션만 남기는 것 |
| four-party card system | 4자 카드 체계 · 카드 소지자·가맹점·발행사·매입사 구조 |
| acquirer | 매입사(가맹점 쪽 은행) · 발행사(issuer)의 반대편 |
| issuer | 발행사 · 여기서는 카드 발행사이자 토큰 발행자, 둘 다 소파이 |
| chargeback | 차지백(카드 결제 취소·환불 청구) · 온체인 대응물이 없는 소비자 보호 장치 |
| dispute finality | 분쟁 확정 · 결제가 되돌려지지 않는다고 확신할 수 있는 시점 |
| cut-off time | 마감 시각 · 그 시각 이후 건은 다음 주기로 넘어감 |
| T+2 | 거래일 + 2영업일 · 자금이 실제로 도착하는 시점을 가리키는 표준 표기 |
| batch | 배치(모아서 한꺼번에 처리) · 실시간(real-time)의 반대 |
| closed loop | 폐쇄 루프 · 발행·계좌·플랫폼이 한 기관 안에 있는 구조. 즉시성의 상당 부분이 여기서 나옴 |
| composite (benefit) | 합성된 (이점) · 두 원인이 섞여 하나처럼 보일 때 |
| to overstate | 과장하다 · "보여진 것보다 과한 말"이라고 지적할 때 |
| national bank charter | 국립은행 인가 · 미국에서 OCC가 내주는 은행 면허 |
| OCC (통화감독청) | Office of the Comptroller of the Currency · 미국 국립은행 감독기관 |
| deposit token | 예금 토큰 · 은행의 부채로서 토큰화된 예금. 준비금 담보 스테이블코인과 구분됨 |
| reserve-backed | 준비금 담보의 · 분리된 자산에 대한 청구권 형태 |
| liability of the bank | 은행의 부채 · 보유자가 무엇을 소유하는지를 결정하는 회계상 위치 |
| redeemable 1:1 | 1대1 상환 가능한 · 토큰 1개를 달러 1개로 바꿀 수 있다는 약속 |
| safeguards | 안전장치 · 마스터카드가 유지한다고 말한 것 |
| the binding constraint | 구속 조건(실제로 발목을 잡는 병목) · 속도 논증에서 가장 느린 부품을 가리킴 |
| permissioned vs permissionless | 허가형 대 무허가형 · 어느 체인인지가 이야기 전체를 바꾼다 |
| blockspace demand | 블록스페이스 수요 · 퍼블릭 체인일 때만 성립하는 파급 |
| load-bearing (claim) | 하중을 받는 (주장) · 다른 주장들이 그 위에 서 있는 핵심 전제 |
