| in the same breath as | ~와 한 숨에, 동시에 언급되며 · 서로 다른 두 사실이 같은 발표에서 같이 나올 때. "in the same breath as a hot August" |
| read as | ~로 읽히다, ~라고 해석되다 · 숫자가 특정 의미로 오해될 때. "the labour market cracked" |
| quietly stronger | 조용히 더 강해진, 눈에 안 띄게 개선된 · 주목받지 못한 채 수치가 좋아졌을 때. "quietly stronger" |
| built on | ~을 기반으로 세워진 · 불안정한 수치 위에 논리가 쌓였을 때. "built on the least stable number" |
