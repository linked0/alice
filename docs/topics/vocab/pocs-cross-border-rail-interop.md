| early-stage | 초기 단계의 · 아직 구체화되지 않은 걸음마 단계를 가리킬 때. "early-stage, with technical, regulatory and governance hurdles outstanding" |
| hub-and-spoke | 허브앤스포크(중심-분산) 구조 · 모든 노드가 중앙 허브 하나만 거치는 네트워크 설계. "each domestic instant-payment system makes one connection" |
| N-squared | N의 제곱, 폭증하는 조합 수 · 참가자 수가 늘수록 연결 수가 기하급수로 느는 문제를 가리킬 때. "instead of N-squared bilateral ones" |
| idle by construction | 구조적으로(설계상) 놀고 있는 · 자본이 원래부터 활용되지 않도록 짜여 있을 때. "that capital is idle by construction" |
| nostro and vostro balances | 노스트로·보스트로 계좌 잔액 · 은행 간 결제를 위해 상대 은행에 미리 예치해 두는 자금. "nostro and vostro balances parked in every corridor" |
| prefunding | 사전 자금 예치 · 결제 전에 미리 자금을 준비해 두는 관행·비용. "required prefunded liquidity" |
| the bar | 비교 기준, 기준점 · 다른 대안을 평가할 때 기준으로 삼는 대상. "that is the bar" |
| put to (a question) | (질문을) ~에게 던지다 · 어떤 대상을 검증할 질문을 제기할 때. "the question to put to it" |
| correspondent banking | 코레스폰던트 뱅킹(환거래은행 제도) · 은행들이 서로 계좌를 터서 국제결제를 대행하는 전통 방식. "correspondent banking handles worst" |
| CBDC | 중앙은행 디지털화폐(Central Bank Digital Currency) · 각국 중앙은행이 발행하는 디지털 화폐, 국가 간 결제망 연결 논의의 핵심 대상. "links between national fast-payment systems and CBDCs" |
| BIS Project Nexus | 국제결제은행(Bank for International Settlements)이 만든 Nexus 프로젝트 · 각국 즉시결제망을 허브 하나로 연결하는, 원장(ledger) 없는 방식의 비교 기준. "using BIS Project Nexus as the no-ledger baseline" |
| mBridge | 여러 중앙은행이 공동 구축한 다중 CBDC 결제용 체인 프로젝트 · 원장을 쓰는 쪽의 비교 대상, 2024년 기준 최소기능제품(MVP) 단계. "mBridge is the ledger arm" |
| PvP | 동시결제(Payment versus Payment) · 두 통화를 서로 동시에 주고받아 한쪽만 먼저 지급하는 결제위험을 없애는 방식. "target the FX and PvP leg" |
| RTGS | 실시간총액결제(Real-Time Gross Settlement) · 건별로 즉시·전액 결제하는 중앙은행 결제망, 국가 간 연결 논의의 기존 인프라 축. "a Nexus-style hub plus existing RTGS" |
| Herstatt exposure | 헤르슈타트 리스크 · 시차 때문에 한쪽이 먼저 지급했는데 상대가 파산해 대금을 못 받는 결제 위험. "that Herstatt exposure is what correspondent banking handles worst" |
| XRPL | XRP 레저(XRP Ledger) · 내장 DEX·오토브리징·에스크로 기능으로 FX와 PvP 구간을 겨냥하는 특정 체인, 이 카드가 실제 검증 대상으로 삼는 예시. "XRPL's relevant features for this are the native DEX" |
| UPI / CIPS | UPI(인도 통합결제인터페이스, Unified Payments Interface)와 CIPS(중국 국경 간 은행 간 결제시스템, Cross-Border Interbank Payment System) · 이번에 연결이 검토되는 두 나라의 실제 결제망 이름. "UPI and CIPS are the systems named" |
