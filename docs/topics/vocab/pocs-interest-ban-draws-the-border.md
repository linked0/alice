|---|---|
| table stakes | 최소한의 기본 요건 · 더 이상 특별할 것 없는 당연한 전제 조건. "all table stakes now" |
| category fence | 카테고리를 가르는 경계선(비유) · 규제가 상품 유형을 구분 짓는 기준선. "it is a category fence" |
| lender of last resort | 최종 대부자 · 위기 시 은행이 기댈 수 있는 중앙은행의 역할. "no lender of last resort" |
| toll | (얻기 위해 치러야 하는) 대가, 통행료 · 특정 지위를 얻으려면 지불해야 하는 비용을 비유. "with a banking license as the toll" |
| one layer up | 한 단계 위(상위 계층)로 · 규제가 미치지 않는 바로 위 계층으로 옮겨간다는 뜻. "moves one layer up, out of the regulated category" |
| live exhibit | 살아있는 실제 사례 · 이론이 아니라 지금 벌어지고 있는 구체적 증거. "is the live exhibit" |
| opt-in | 선택적으로 참여하다, 자발적으로 따르다 · 외국 발행자가 자발적으로 규제를 준수하는 방식. "Opt-in if compliant" |
| passporting | 패스포팅(단일 인가로 여러 나라 영업 허용) · EU 금융 규제 특유의 상호인정 제도. "Passporting rules" |
| a run on | ~에 대한 대규모 인출 사태(뱅크런) · 신뢰가 흔들려 한꺼번에 빠져나가는 상황. "a run on it looks exactly like a money-market-fund run" |
| by virtue of | ~라는 이유만으로, ~함으로써 · 법률 문구에서 원인을 나타낼 때. "interest or other returns by virtue of holding" |
