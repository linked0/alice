| self-reference / self-referential | 자기지시(적)(체계가 자기 자신을 가리키는 것) · 시장·감사 규칙을 읽을 때도 쓰는 개념. "reading a system from inside its own self-reference" |
| throughline | 관통선(여러 작품·장면을 잇는 공통 주제) · 열 권을 묶는 세 갈래를 부를 때. "The pettiness throughline" |
| pettiness | 지질함, 옹졸함(사소하고 부끄러운 인간적 약점) · 도스토옙스키·로스 항목의 공통 소재. "a narrator's private smallness" |

| unreliable narrator | 신뢰할 수 없는 화자(사실 판단을 전적으로 믿을 수 없는 1인칭 화자) · 문예비평의 표준 용어, 지하생활자류 화자에 적용. (개념어, 본문 대응 표현 없음) |
| restraint | 절제(감정·판단을 억누르는 서술 태도) · 레비와 에르노를 묶는 규율. "the restraint is what makes the account universal" |
| bear witness | 증언하다, 목격자로서 기록을 남기다 · 프리모 레비식 기록의 태도를 가리킴. (개념어, "some experiences need exactly this kind of witness"와 연결) |
| autofiction | 오토픽션(자전적 사실과 허구를 섞은 소설 형식) · 아니 에르노 작품군을 가리키는 표준 장르어. (원문 요약에 등장한 장르 표현) |
| non-linear (structure) | 비선형(적) 구조(순서대로 읽지 않아도 되는 구성) · 『하자르 사전』의 형식 실험. "a non-linear novel-as-dictionary" |
| hedge (v./n.) | 확답을 피하다, 에두르기(단정하지 않고 여지를 두는 말) · 스트라우트 화자의 정직함의 핵심. "Strout's narrators become truthful exactly when they hedge" |
| pathos | 파토스(독자의 연민·슬픔을 불러일으키는 정서적 힘) · 로스 『울분』을 설명할 때 쓰는 비평 용어. (원문 요약의 "파토스와 아이러니의 절정") |
| irony | 아이러니(의도와 결과, 겉과 속이 어긋나는 상황) · 이 항목 제목의 키워드이자 정영수 리스트 전체의 대비축. "irony" |
| indignation | 울분, 분개(부당함에 대한 억눌린 분노) · 필립 로스 소설 제목이자 청년의 감정 상태. "*Indignation*" |
| beauty contest | 미인 대회(케인스가 든 비유, 남들의 예측을 예측하는 게임) · 시장 가격을 재귀적 기대로 읽을 때 쓰는 이론 용어. "the beauty contest, four centuries early" |
| reflexive (expectations) | 재귀적인(기대가 기대 자신을 되먹임하는) · Verex/Theory 랜딩 문장에서 쓴 표현. "reflexive expectations" |
| publication order | 출간 순서(개인 취향 순위가 아니라 나온 순서로 나열) · 정영수가 열 권을 배열한 원칙. "ordered his ten picks by publication date" |
| 1:1 (one-on-one) | 일대일 면담(팀장·팀원 간 정기 개인 면담) · Eng 랜딩에서 누네스의 질문을 쓰는 자리. "a working opener for a 1:1" |
