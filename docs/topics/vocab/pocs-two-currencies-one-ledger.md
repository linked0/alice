| Expression | 뜻 · 쓰이는 자리 |
|---|---|
| option on distribution | 배포 가능성이지 실제 배포는 아닌 것 · 잠재력과 실현을 구분할 때. "it is an option on distribution, not distribution" |
| throw off (yield) | 수익을 내다, 발생시키다 · 준비자산이 이자를 만들어내는지 말할 때. "Euro reserves do not throw off the same yield" |
| earn the float | 예치 자금 운용으로 수익을 내다 · 발행사가 준비금으로 돈을 버는 구조. "issue it and earn the float is a thinner story" |
| cross | 통화를 환전하다, 다른 통화로 교환하다 · 외환 거래를 가리키는 동사. "If crossing EUR to USD on-chain costs several times" |
| adjacency | 서로 인접해 있을 뿐인 상태 · 실제 거래가 이뤄지는 시장과 구분할 때. "composability has produced adjacency rather than a market" |
| category error | 범주 오류 · 서로 다른 종류의 것을 같은 것으로 착각하는 오류. "Category error — Revolut's user count, not Ethereum's" |
| unfalsifiable | 반증이 불가능한 · 검증할 방법이 없는 주장을 가리킴. "Unfalsifiable as stated" |
| settle (a claim) | 분쟁·주장을 판가름하다, 결론짓다 · 무엇이 최종적으로 증명하는지 말할 때. "will be settled by spreads and depth, not by launches" |
| bearer instrument | 무기명 증권·자산 · 보유 자체가 권리가 되는 금융상품. "fiat currencies as bearer instruments on the same ledger" |
| load-bearing | 핵심을 떠받치는, 구조상 진짜 중요한 · 세 주장 중 검증 가능한 것이 핵심이라는 뜻. "the checkable one happens to be the load-bearing one" |
| quoted depth | 호가 물량, 시장 깊이 · 특정 가격에 거래 가능한 규모. "record quoted depth at several sizes" |
