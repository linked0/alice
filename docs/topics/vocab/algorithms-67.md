| Expression | 뜻 · 쓰이는 자리 |
|---|---|
| in practice | 실제로는, 현실적으로 · 이론과 달리 실제 시스템이 어떻게 동작하는지 말할 때. "message delivery is in practice either at-most-once" |
| dual-write problem | 이중 쓰기 문제 · 두 시스템에 원자적으로 동시에 쓸 수 없는 문제. "the dual-write problem" |
| relay | 중계하다, 중계 프로세스 · 아웃박스 테이블을 읽어 메시지 브로커로 넘기는 역할. "a separate relay process reads the outbox" |
| force-kill | 프로세스를 강제로 죽이다 · 장애 상황을 재현해 테스트할 때. "force-kill the process right after publishing" |
| bind ... together | ~을 하나로 묶다 · 원장 업데이트와 트랜잭션 발행을 한 트랜잭션으로 묶는다는 뜻. "binding the off-chain ledger update and the transaction" |
| double settlement | 이중 정산 · 같은 결제가 두 번 처리되는 오류. "the standard fix to prevent double settlement" |
