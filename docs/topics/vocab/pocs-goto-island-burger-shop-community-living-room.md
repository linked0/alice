| Expression | 뜻 · 쓰이는 자리 |
|---|---|
| third place | 제3의 장소(집·직장이 아닌 머무는 곳) · 사회학 용어, 커뮤니티 공간을 설명할 때. "A 'third place' (not home, not work) only functions as one" |
| community living room | 공동체의 거실(누구나 들를 수 있는 공유 공간이라는 비유) · 이 항목의 핵심 인용구. "our real purpose is to create a community living room" |
| load-bearing | 하중을 떠받치는(비유적으로 "없으면 무너지는 핵심 기능") · 건축 용어를 조직·공동체 논의에 빌려 쓴 표현. "A community living room is load-bearing" |
| costly signal(ing) | 값비싼 신호(말로만이 아니라 대가를 치러야 증명되는 헌신의 표시) · 진화생물학·사회학에서 온 개념. "costly, ongoing signals of commitment" |
| barter | 물물교환(화폐 없이 물건과 물건을 맞바꾸는 거래) · 가격 시장과 대비할 때. "sashimi traded for burgers is barter, not a sale" |
| single-origin | 단일 산지(원료가 특정 한 곳에서만 온다는 뜻) · 커피·식재료 품질을 말할 때 흔한 표현. "a named, local, single-origin beef" |
| heritage tourism | 유산 관광(과거·전통을 관광 상품으로 전시하는 관광 형태) · 마을을 "박물관화"하는 방식을 가리킬 때. "heritage tourism that treats a village as a museum" |
| outer islands | 외딴섬들(본토에서 먼 섬 지역) · 일본 지리·정책 논의에서 자주 쓰는 표현. "Japan's outer islands are depopulating" |
| depopulation | 인구 감소(지역에서 사람이 줄어드는 현상) · 지방 소멸 논의의 핵심 명사. "a widely documented trend" |
| preservation society | 보존회(전통·기술을 지키기 위해 모인 단체) · 지역 문화 활동을 가리킬 때. "the local Kagura preservation society" |
| wagyu | 와규(일본산 소고기 브랜드 총칭) · 고토규처럼 지역별 브랜드가 있는 상위 범주. "a recognized Nagasaki wagyu brand" |
| storefront | 점포(길가에 면한 가게 건물) · 오래된 건물을 가리킬 때. "an 80-year-old storefront" |
| turnover | 회전율(손님이 얼마나 빨리 바뀌는지, 식당 매출 회전) · 요식업 용어. "proximity a normal restaurant's turnover doesn't allow" |
| transplant (n.) | 이주민(다른 지역에서 옮겨 온 사람) · "심은 사람"이라는 원뜻에서 온 비유. "Kyoto-transplants who happen to live on an island" |
| proximity | 근접성(물리적으로 가까이 있음) · 서로 다른 집단이 한 공간에 섞이는 것을 설명할 때. "proximity a normal restaurant's turnover doesn't allow" |
| showmanship | 과시(보여주기 위한 기교, 실속보다 인상 위주의 연출) · 절제된 장인정신과 대비할 때. "Nothing here is showmanship" |
| subtraction | 뺄셈(더하지 않고 덜어내는 방식의 디자인 전략) · 최소 반죽 같은 절제된 기법을 가리킬 때. "the craft move is subtraction" |
| ritual | 의례(정해진 절차로 반복되는 문화 행사) · 가구라·오봉 같은 지역 전통을 가리킬 때. "being accepted into the place's rituals" |
| on purpose | 의도적으로, 일부러 · 우연이 아니라 선택했음을 강조. "picked a specific remote place on purpose" |
| pass through (phrasal verb) | 잠시 들렀다 지나가다 · 정착하지 않고 오가는 여행자를 가리킬 때. "travelers pass through" |
| retreat (n.) | 은신처, 도피처(혼자 조용히 쉬러 가는 곳) · "community living room"과 대비되는, 공동체 기능이 없는 이주의 실패 양상. "treating the move as a private retreat" |
