| Expression | 뜻 · 쓰이는 자리 |
|---|---|
| MoU (memorandum of understanding) | 양해각서 — 구속력 없는 합의 · 일정이 없다는 점이 핵심 |
| proof of concept (PoC) | 개념 검증, 되는지만 확인하는 시험 |
| distribution | 유통 — 제품을 사용자에게 닿게 하는 경로 · "Kakao Pay is distribution" |
| balance sheet | 재무상태표 — 여기서는 "부채를 질 수 있는 주체"라는 뜻 |
| deposit-taker | 수신 기관, 예금을 받을 수 있는 곳 |
| custody | 수탁, 자산 보관 · MPC 키 관리가 그 형태 |
| MPC (multi-party computation) | 다자간 연산 — 키를 쪼개 보관하는 방식 |
| issuer | 발행사 · Circle은 달러의 발행사이지 원화의 발행사가 아니다 |
| mint/redeem | 발행·상환 · 스테이블코인 페그를 유지하는 배관 |
| vendor | 벤더, 공급업체 — **거래 상대방(counterparty)이 아니다** |
| counterparty | 거래 상대방, 반대편에서 위험을 지는 쪽 |
| an empty seat | 비어 있는 자리 · 빠진 참여자를 가리키는 비유 |
| the scarce asset | 희소한 자산 — 돈으로 살 수 없는 것 |
| on-ramp | 온램프, 법정화폐에서 토큰으로 들어가는 입구 |
| travel rule | 트래블룰 — 가상자산 이전 시 송수신인 정보 제공 의무 |
| supervisor | 감독당국 · regulator와 거의 같은 뜻, 은행 쪽에서 더 자주 쓴다 |
| availability dependency | 가용성 의존성 — 멈추면 우리도 멈추는 외부 요소 |
| to be pre-answered | 이미 답이 정해져 있다 · "the question is largely pre-answered" |
| load-bearing claim | 하중을 지는 주장 — 틀리면 글 전체가 무너지는 전제 |
| worked example | 실제로 풀어 본 예시 · "a worked example of the split" |
