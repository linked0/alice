| Expression | 뜻 · 쓰이는 자리 |
|---|---|
| thought-prison | 생각의 감옥(스스로 만든 좁은 사고 패턴에 갇힌 상태) · 이 항목의 핵심 은유. "the way out of that room" |
| counterweight | 반대추(한쪽으로 쏠리는 것을 상쇄하는 것) · 영상 편중 습관을 균형 잡는 개념으로. "a deliberate counterweight" |
| compounding | 복리(작은 효과가 반복되어 누적되는 것) · 원래 금융 용어, 여기선 반복 사고의 누적을 설명. "a point about compounding" |
| friction | 마찰(저항, 쉽게 넘어가지 않고 걸리는 지점) · 책이 만드는 느린 사고 과정을 설명. "that friction is what actually moves an opinion" |
| rerun | 재방송(예전 것의 반복 방영) · 반복되는 생각이나 의견을 비유적으로. "mostly reruns" |
| through line | 관통선(여러 작품·항목을 잇는 하나의 주제) · Eng 면접 답변에서 강조된 개념. "a through line, not a title" |
| citation tracing | 인용 추적(주장을 원 출처 문헌까지 거슬러 올라가는 것) · `research-any-topic-like-a-phd`와 연결되는 방법론. "citation tracing... is also how you find the next book" |
| case study | 사례 연구(이론이 아니라 구체적 사례를 분석하는 방법) · 그린 책들의 서술 방식. "historical-case-study books, not theory books" |
| well-attested / well-documented | 잘 입증된/잘 문서화된 · 사실 확인 단락에서 검증 가능성을 표현. "real, well-attested works" |
| take on faith | 그대로 믿다(검증 없이 받아들이다) · Verified/unverified 구분에서 쓰는 표현. "verified claim vs. taken-on-faith claim" |
| step off the train | (반복되는) 열차에서 내리다(습관적 사고 패턴을 벗어나다) · `systems-thinking-cynefin-dart`와 연결. "step off a train of repeated thinking" |
| live item | 진행 중인 항목(아직 마무리되지 않고 현재 다루는 항목) · 습관을 기존 항목에 묶는 제안에서. "tied to a live item" |
| hold up (v.) | (검증 후에도) 유효하다, 무너지지 않다 · 책을 읽은 뒤 기존 항목을 재점검할 때. "whether the item held up" |
| spine (metaphor) | 중심축, 줏대(뼈대가 되는 일관된 관점) · "양적 팽창"과 대비되는 개념. "volume without a spine" |
| sit with (an idea) | (생각을) 오래 붙들고 있다, 곱씹다 · 빠른 소비와 대비되는 느린 독서를 표현. "you sit with one argument" |
| lineage | 계보, 혈통(사상이나 주장이 이어져 온 경로) · 생각이 물려받은 것임을 표현. "a traceable lineage" |
| deep dive / go deep | 깊이 파고들다 · 스크롤·짧은 콘텐츠와 대비되는 독서 태도. "willing to go deep into a book" |
| corrective (n.) | 교정 장치, 바로잡는 것 · 이 항목이 "해야 할 일"이 아니라 균형을 맞추는 장치임을 표현. "lands as a corrective, not a chore" |
| propose only, not implemented | 제안일 뿐 구현하지 않음 · 태그/소스 필드 제안 시 명시한 범위 한정 표현. "Proposal only, not implemented here" |
| addiction (healthiest) | (가장 건전한) 중독 · 그린이 독서를 표현한 말, 과장 없이 습관의 강도를 전달. "the healthiest addiction he has" |
