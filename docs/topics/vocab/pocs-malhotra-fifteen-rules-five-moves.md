| Expression | 뜻 · 쓰이는 자리 |
|---|---|
| **equip your advocate** | 내 편을 무장시키다 — 상대 조직에서 나를 변호할 사람에게 논거를 쥐여주는 것 |
| **go to bat for someone** | 남을 위해 대신 나서다 (야구 비유). 기사 원문 표현 |
| **break precedent** | 전례를 깨다 — HR이 못 하는 일의 대표 |
| **ironclad constraints** | 철벽 같은 제약. 협상으로 풀리지 않는 것 |
| **an exploding offer** | 시한부 오퍼 — 빨리 수락할수록 조건이 좋아지는 구조 |
| **a stalking horse** | 들러리, 다른 쪽 값을 올리는 데 쓰이는 대상 |
| **negotiate serially vs simultaneously** | 순차 협상 대 동시 협상 — 이 기사의 핵심 전술 |
| **signal the relative importance** | 상대적 중요도를 알리다 = 순위를 붙이다 |
| **haggle over every little thing** | 사소한 것마다 흥정하다 |
| **rub people the wrong way** | 사람 심기를 건드리다 |
| **downplay** | 축소해 다루다, 대수롭지 않게 넘기다 |
| **become wedded to a position** | 어떤 입장에 매이게 되다 — 최후통첩을 굳히지 않게 하라는 맥락 |
| **maintain a sense of perspective** | 균형 감각을 유지하다 |
| **second-order** | 이차적인 — 중요하지만 결정적이지는 않은 |
