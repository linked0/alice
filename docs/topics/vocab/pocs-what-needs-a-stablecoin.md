| Expression | 뜻 · 쓰이는 자리 |
|---|---|
| the incumbent to beat | 이겨야 할 기존 강자(현재 표준) · 새 기술이 대체하려는 비교 기준을 말할 때. "the incumbent to beat is not slow settlement" |
| a screen that never rejects | 아무것도 걸러내지 못하는 테스트 · 모든 후보가 통과하는 무의미한 심사 기준을 가리킬 때. "A screen that never rejects is not a screen." |
| disqualifier | 탈락시키는 기준, 자격 박탈 요소 · 테스트가 후보를 걸러낼 때 쓰는 결정적 조건. "the closing line is the disqualifier stated plainly" |
| sit on | (비용·문제가) ~단계에 위치하다, 걸려 있다 · 특정 구간에 해당 요소가 존재함을 말할 때. "none of them sit on the domestic leg" |
| the far side | 거래·국경의 반대쪽 당사자 · 국경 간 거래에서 상대방을 가리킬 때. "The far side wants dollars." |
| fudge it | 얼버무리다, 대충 넘기다 · 불편한 사실을 명확히 밝히지 않고 넘어갈 때. "more useful than fudging it" |
| carry inside | (수치·요인을) 내재하다, 안에 담고 있다 · 어떤 성장률이 다른 배경 요인을 포함할 때. "carries global dollar demand inside it" |
| measured against | ~을 기준으로 평가되다 · 후보를 비교 대상과 견줄 때. "a US stablecoin is measured against ACH" |
| go nowhere | 성과 없이 끝나다, 진전이 없다 · 아이디어나 시도가 결실을 못 맺을 때. "keep going nowhere: they are scored against the wrong baseline" |
| necessary, never sufficient | 필요조건이지만 충분조건은 아닌 · 하나의 조건만으로는 부족함을 말할 때. "(necessary, never sufficient)" |
| the trap underneath the trap | 함정 속에 숨은 또 다른 함정 · 겉보기 경고 뒤에 더 근본적인 문제가 있을 때. "The trap underneath the trap" |
