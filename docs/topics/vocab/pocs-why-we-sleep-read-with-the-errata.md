| Expression | 뜻 · 쓰이는 자리 |
|---|---|
| **a claim bigger than its evidence** | 증거보다 큰 주장 |
| **fact-check** (동사) | 사실 확인을 하다 |
| **a systematic review** | 체계적 문헌고찰 — 개별 연구가 아니라 연구 전체를 훑는 방법 |
| **a U-shaped relationship** | U자형 관계. 양 극단에서 위험이 오르는 형태 |
| **relative risk vs. effect size** | 상대위험 대 효과 크기 — "두 배"가 위험한 이유 |
| **correlation, not causation** | 상관이지 인과가 아님 |
| **cherry-picking / omitting a data point** | 유리한 것만 고르기 / 데이터를 빼기 |
| **institutional response** | 기관의 공식 입장 (검증과는 다르다) |
| **a corrected second edition** | 오류를 고친 2판 |
| **sleep pressure** | 수면 압력 — 깨어 있는 시간이 쌓아 올리는 졸림 |
| **sleep hygiene** | 수면 위생 — 잠을 위한 습관 규칙 |
| **CBT-I** | 불면증 인지행동치료 |
| **bad health numbers are not neutral** | 틀린 건강 수치는 중립적이지 않다 |
