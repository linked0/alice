| pattern recognition | 패턴 인식 · 도파민 트리거 중 하나, 습관 루프의 근거. "the Sudoku click" |

| through line | 관통선(여러 관심사를 하나로 꿰는 축) · 그린 항목과 연결되는 개념. "curiosity has to become passion before it becomes flow" |
| rule of thumb | 어림값, 경험칙(정밀한 상수가 아닌 대략적 지침) · 15분 인터럽션 비용에 붙인 단서. "a rule of thumb, not a precise constant" |
| calibrated (task) | (과제가) 잘 조정된 · 도전-역량 비율이 맞는 상태를 가리키는 말. "is the task calibrated" |

| protected block | 보호된(방해받지 않는) 시간 블록 · 90-120분 규칙의 실행 형태. "a protected 90-120 minute block" |
| anchor (for attention) | 닻(주의를 오래 붙잡아 두는 고정점) · 목적(purpose)의 역할을 설명하는 은유. "Passion needs an anchor, which is purpose" |
