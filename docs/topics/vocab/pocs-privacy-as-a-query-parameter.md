| Expression | 뜻 · 쓰이는 자리 |
|---|---|
| query parameter | 쿼리 파라미터 · URL의 `?key=value` 부분. 이 카드가 뉴스로 꼽은 것 |
| shielded transfer | 실드 전송 · 송신자·수신자·금액을 가린 이전. Zcash가 푼 문제 |
| shielded pool | 실드 풀 · 가려진 가치가 머무는 집합 |
| anonymity set | 익명 집합 · 나와 구별되지 않는 사람들의 무리. 프라이버시의 실제 강도 |
| indistinguishable from | ~와 구별되지 않는 · 프라이버시 보장의 정확한 형태 |
| to leak (state) | (상태가) 흘리다 · 숨긴 정보가 다른 경로로 드러나는 것 |
| state delta | 상태 변화량 · 리저브가 얼마나 움직였는가. 거래를 복원하는 단서 |
| observability | 관측 가능성 · 바깥에서 볼 수 있는 정도 |
| reserves | (풀의) 리저브 · AMM이 보유한 두 자산의 잔고 |
| counterparty | 거래 상대방 · 스왑에서는 공용 AMM 풀 |
| invariant | 불변식 · 증명이 세워야 하는, 항상 참이어야 할 조건 |
| double-spend | 이중지불 · 같은 돈을 두 번 쓰는 것 |
| nullifier | 널리파이어 · 무엇이 소비됐는지 밝히지 않고 재사용을 막는 표시 |
| replay | 재생(재사용 공격) · 이미 쓴 권한을 다시 제출하는 것 |
| batching | 배칭 · 여러 거래를 묶어 하나의 상태 변화로 만드는 것 |
| netting in aggregate | 총량으로 상계하다 · 개별 건을 감추고 합계만 드러내는 정산 |
| encrypted order | 암호화 주문 · 실행 시점까지 내용을 가린 주문 |
| intent (design) | 인텐트 설계 · 사용자가 원하는 결과만 표명하고 솔버가 실행하는 구조 |
| solver | 솔버 · 인텐트를 실제 거래로 바꿔주는 참여자 |
| opt-in | 옵트인(기본 꺼짐, 켜야 적용) · 반대는 default-on |
| self-selected | 자기선택된 · 스스로 고른 집단. 그래서 관찰자에게 흥미로운 집단 |
| a disclosure | 정보 공개 · 감추려는 행위가 오히려 드러내는 것 |
| the binding constraint | 구속 조건 · 실제로 발목을 잡는 요소 |
| waypoint vs destination | 경유지 대 목적지 · 토글은 경유지, 기본값이 목적지 |
| composable with the product surface | 제품 표면과 조합 가능한 · 별도 앱이 아니라 기존 흐름 안에 들어간 상태 |
| general availability | 일반 가용성 · 모두에게 열려 있는 상태. 링크가 있다고 증명되지 않음 |
| proving cost | 증명 비용 · 영지식 증명을 만드는 데 드는 계산·시간 |
| trust assumption | 신뢰 가정 · 안전하려면 누구를 믿어야 하는가 |
