|---|---|
| engine-ready | 엔진에 바로 넣을 수 있는 · 임포트된다는 뜻이지 씬 성능이 나온다는 뜻은 아니라는 §5의 지적 |
| tri budget (triangle budget) | 트라이앵글 예산 · 메시가 써도 되는 삼각형 수의 상한 |
| to remesh to a budget | 예산에 맞춰 리메시하다 · 예산이 입력이 되는 것. 이 카드가 꼽은 핵심 표현 |
| retopology (retopo) | 리토폴로지 · 생성된 메시를 쓸 수 있는 토폴로지로 다시 짜는 작업 |
| topology | 토폴로지 · 면과 엣지가 흐르는 방식. 변형 품질을 결정 |
| to bake (maps) | (맵을) 굽다 · 고해상도 표면 정보를 텍스처로 옮겨 담는 것 |
| high-to-low bake | 하이폴리 → 로우폴리 베이크 · 디테일 전사의 표준 절차 |
| normal map / ambient occlusion | 노멀 맵 / 앰비언트 오클루전 · 로우폴리가 입는 디테일 정보 |
| UV unwrap / UV layout | UV 언랩·레이아웃 · 3D 표면을 2D 텍스처 공간에 펼친 것 |
| seam | 심(이음매) · 언랩이 잘린 자리. 나쁘면 표면이 찢어져 보인다 |
| texture atlas | 텍스처 아틀라스 · 여러 에셋의 맵을 한 장에 모은 것. 드로우콜을 줄인다 |
| draw call | 드로우콜 · GPU에 그리라고 보내는 호출. 많을수록 느려진다 |
| LOD (level of detail) | 상세 수준 · 거리에 따라 바꿔 쓰는 저폴리 버전 |
| collision mesh | 콜리전 메시 · 물리 충돌용 단순 형상. 시각 메시와 별개 |
| lightmap UV | 라이트맵 UV · 구운 조명을 담기 위한 두 번째 언랩 |
| rig / skeleton | 리그·골격 · 캐릭터를 움직이게 하는 뼈대 구조 |
| skin weights | 스킨 웨이트 · 각 정점이 어느 뼈를 얼마나 따르는지의 값 |
| T-pose | T 포즈 · 팔을 벌린 표준 기본 자세 |
| IK-ready | IK 준비가 된 · 역운동학으로 바로 조작 가능한 상태 |
| to deform without artifacts | 아티팩트 없이 변형되다 · 좋은 스킨 웨이트의 정의 |
| interchange format | 교환 포맷 · 도구 사이를 건너가는 형식. 여기서는 GLB |
| to produce to spec | 사양에 맞춰 생산하다 · 도구가 인프라가 되는 조건 |
| a source of material vs a pipeline step | 재료의 출처 대 파이프라인의 한 단계 · 도구의 위상 차이 |
| throughput | 처리량 · 이번에 실제로 측정된 것 |
| to raise the prior | 사전 확률을 올리다 · 증명은 아니지만 믿음이 강해지는 상황 |
| the claim on file | 파일에 적힌 주장 · 원래 검증하려던 것 |
