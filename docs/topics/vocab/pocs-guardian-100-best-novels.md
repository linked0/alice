| Expression | 뜻 · 쓰이는 자리 |
|---|---|
| **provenance** | 출처·내력. 미술품 용어인데 데이터·문서·주장 전부에 씀. false provenance = 거짓 출처 |
| **a name that does not hold** | 성립하지 않는 이름. hold = (주장·설명이) 버티다, 유효하다 |
| **load-bearing** | 하중을 받는. 건축 용어를 비유로 — "the falsehood is load-bearing" = 그 거짓이 구조를 떠받치고 있다 |
| **caught in the act** | 현행범으로 잡힌. 실패 사례를 실시간으로 포착했을 때 |
| **catholic** (소문자) | 폭넓은, 편식하지 않는. 종교와 무관한 형용사 용법 |
| **broadly defensible** | 대체로 방어 가능한. 완벽하진 않지만 옹호할 수 있다는 절제된 긍정 |
| **it does not survive X** | X를 견디지 못한다. 주장이 검증을 통과하지 못할 때의 정확한 동사 |
| **the cheapest tell** | 가장 싼 단서. tell = (포커) 무심결에 드러나는 신호 |
| **read X for wear** | X가 닳은 흔적을 읽다. 품질·진위를 흔적으로 판별할 때 |
| **the downgrade a sentence needs** | 문장에 필요한 하향 조정. 과장된 주장을 참인 범위로 좁히는 일 |
| **pass it on** | (그대로) 넘기다, 전달하다 |
| **as much as is known** | 알려진 만큼. 더도 덜도 아니게 인용하라고 할 때 |
