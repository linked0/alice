| Expression | 뜻 · 쓰이는 자리 |
|---|---|
| time affluence | 시간의 풍요(시간을 돈처럼 지켜야 할 자원으로 보는 개념) · 이 항목의 세 번째 규칙. "treat time, not just money, as a resource worth protecting" |
| time famine | 시간 기근(만성적으로 시간이 없다고 느끼는 상태) · 웰빙 연구의 용어. "A 'time famine' ... hurts wellbeing" |
| self-compassion | 자기연민(실패한 자신을 친구 대하듯 대하는 태도) · 두 번째 규칙, 크리스틴 네프 연구의 핵심어. "self-compassion beats self-criticism" |
| self-criticism | 자기비판 · self-compassion과 대비되는, 동기부여가 아니라 수치심을 낳는 습관. "harsh self-criticism predicts procrastination and shame" |
| inner voice | 내면의 목소리(머릿속에서 자신에게 말하는 방식) · 고성과자의 "squeeze more" 목소리를 가리킬 때. "an internal voice that says 'squeeze more'" |
| dashboard light | 계기판 경고등(정보를 알리는 신호, 무시할 성가심이 아님) · 첫 번째 규칙의 핵심 비유. "negative emotions are dashboard lights" |
| tyre-pressure light | 타이어 공기압 경고등 · dashboard light와 같은 뜻으로 쓰인 구체적 예시. "a tyre-pressure warning light is information" |
| red alert | 적색 경보(즉시 조치가 필요하다는 신호) · 압도감을 표현할 때. "overwhelm is a red alert" |
| take X off the plate | 할 일 목록에서 하나를 덜어내다 · 압도감에 대한 구체적 대응. "take one thing off the plate" |
| buy time | 시간을 벌다/사다(위임 등으로 시간을 확보하다) · 세 번째 규칙의 처방. "buy it back by delegating" |
| delegate (v.) | 위임하다(일을 다른 사람이나 도구·에이전트에 넘기다) · Tech 섹션 연결의 핵심 동사. "handing routine work to tools or agents" |
| burnout | 번아웃(탈진, 소진) · 성취·돈 과잉 투자가 낳는 결과. "chronic anxiety and burnout" |
| chronic anxiety | 만성 불안 · burnout과 짝을 이루는 결과. "drives chronic anxiety and burnout" |
| procrastination | 미루기(할 일을 늦추는 것) · 자기비판이 낳는 결과, 동기부여가 아님. "predicts procrastination and shame" |
| shame | 수치심 · procrastination과 함께 자기비판의 결과로 언급됨. "procrastination and shame, not better output" |
| knowledge worker | 지식노동자(주로 지식·정보를 다루는 직업군) · 번아웃 패턴이 나타나는 집단. "shows up in students and knowledge workers alike" |
| counterweight | 대응추, 균형추(반대쪽에서 균형을 잡아주는 것) · 이 항목이 다른 Tech 항목과 맺는 관계. "this is the counterweight to today's Tech item" |
| queueing problem | 큐잉 문제(줄 세우기·순서 재정렬로 접근하는 문제) · 시간 부족을 다루는 한 가지 방식, 이 항목이 반박하는 프레임. "'not enough time' as a queueing problem" |
| wellbeing | 웰빙, 안녕감(삶의 질·행복 수준을 가리키는 연구 용어) · 이 항목 전체의 상위 주제. "not weighted equally in wellbeing research" |
