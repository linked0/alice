| Expression | 뜻 · 쓰이는 자리 |
|---|---|
| systems thinking | 시스템 사고(부분이 아니라 그 이면의 연결·패턴을 읽는 인지 능력) · 이 글 전체의 주제. "the cognitive skill of reading the connections and repeating patterns" |
| Cynefin framework | 커네빈 프레임워크(데이브 스노든이 만든 4가지 시스템 유형 분류법) · 이 글의 핵심 틀. "the Cynefin framework's four domains" |
| domain | 영역, 유형(Cynefin에서 Clear/Complicated/Complex/Chaotic 각각을 부르는 말) · 분류 단위. "which of the four domains" |
| cobra effect | 코브라 효과(잘못된 지표에 보상을 걸면 그 지표 자체가 악용되는 현상) · 역인센티브의 대표 사례. "rewarding the wrong metric gets the system gamed" |
| perverse incentive | 역인센티브(의도와 반대로 작동하는 유인) · cobra effect를 설명하는 상위 개념. "a perverse-incentive story" |
| delayed feedback | 지연된 피드백(보상은 즉시, 대가는 나중에 오는 구조) · 흡연 예시가 대표적. "the reward is immediate and the damage lands decades later" |
| checklist | 체크리스트(Clear 영역의 표준 대응) · 절차를 빠짐없이 따르는 도구. "follow the checklist" |
| contract rider | 계약 특약 조항(공연 계약 등에 붙는 부가 조건) · Van Halen의 갈색 M&M 조항을 가리키는 말. "Van Halen's touring contract famously buried a clause" |
| probe | 프로브, 작은 실험(Complex 영역에서 계획 대신 쓰는 작은 시도) · 이 글에서 반복되는 핵심 동작. "run small experiments — probes" |
| probe-sense-respond | 프로브-감지-대응(Complex 영역의 Cynefin 표준 대응 절차) · sense-categorise-respond 등과 짝을 이루는 용어. "sense-categorise-respond, sense-analyse-respond, probe-sense-respond, act-sense-respond" |
| stabilize first, ask later | 먼저 안정화하고 나중에 묻는다(Chaotic 영역의 원칙, 분석 마비를 피하는 행동 지침) · 타이레놀 리콜이 예. "stop analyzing and act to stabilize first, ask later" |
| DART | Deconstruct(해체)·Analyze(분석)·Recognize(인식)·Test(테스트)의 머리글자, 스와디아 본인의 진단 니모닉 · 4가지 유형을 판별하는 4단계 질문. "DART, a four-question diagnostic" |
| premise line | 전제 문장(어떤 시도를 시작하기 전에 미리 적어두는 가정) · 프로브가 실패해도 배울 거리를 남기게 하는 장치. "the premise line ... is what turns a guess into something you can learn from" |
| false dichotomy | 거짓 이분법(둘 중 하나만 가능하다는 잘못된 전제) · "페라리냐 토요타냐" 예시. "break a false dichotomy" |
| self-definition / identity | 자기 규정, 정체성(가장 바꾸기 어려운 시스템으로 언급됨) · 영상의 마무리 논점. "the hardest system to redesign ... is your self-definition and identity" |
| root cause | 근본 원인(사후에 분석해 밝혀내는 원인) · Chaotic 예시에서 원인 규명 전 행동했다는 대비로 등장. "before the root cause was established" |
| domain mismatch | 유형 불일치(문제의 성격과 다른 방법을 적용하는 실수) · Why 문단의 핵심 개념. "a domain-matching error" |
| M&A | Merger and Acquisition(인수합병) · Complex 영역 예시(합병 후 조직문화 통합)에서 쓰이는 약어. "post-merger culture integration" |
| ER | Emergency Room(응급실) · Complicated 영역 예시(응급실 흉통 진단). "An ER doctor diagnosing chest pain" |
| pilot | 파일럿, 시범 시행(전면 투입 전 가장 작은 규모로 해보는 테스트) · DART의 Test 단계에서 쓰는 말. "the smallest possible pilot before committing fully" |
