| Expression | 뜻 · 쓰이는 자리 |
|---|---|
| time-box | 시간을 정해놓고 시도해보다 · 무한정 고민 말고 제한 시간 안에 실행해볼 때. "time-box it: stand up the first invariant alert" |
| stand up | (시스템·서비스를) 구축해 세우다 · 새 알림·서버를 처음 띄울 때 쓰는 구동사. "stand up the first invariant alert in Tenderly" |
| ship it | (일단) 내보내다, 배포하다 · 완벽하지 않아도 실전에 적용할 때 쓰는 표현. "ship it and migrate to your own stack later" |
| blind spot | 사각지대 · 감시가 닿지 않아 못 보는 위험 구간을 가리킬 때. "vendor outage = no eyes" |
| removes the excuse | 핑곗거리를 없애다 · 하지 않을 이유였던 것을 제거할 때. "removes the setup-cost excuse for not having one" |
| stuck for days | 며칠째 진척이 없다 · 작업이 막혀 오래 지연되고 있을 때. "If your monitoring has been stuck for days" |
| start-cost decision | 시작 비용에 관한 결정 · 장단점이 아니라 초기 진입 비용으로 도구를 고를 때. "Not a build — a start-cost decision" |
| coverage | (감시·보장) 범위 · 완벽하진 않아도 지금 확보하는 감시 범위를 말할 때. "coverage today beats a perfect stack next month" |
