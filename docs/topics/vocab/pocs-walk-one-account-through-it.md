| Expression | 뜻 · 쓰이는 자리 |
|---|---|
| a working note | 작업 노트 — 결론이 아니라 진행 상황을 적은 글 |
| to make the case for X | X를 해야 하는 이유를 세우다 — 설득 문서의 표준 표현 |
| an ecosystem survey | 생태계 설문 — 이해관계자들에게 실제 수요를 묻는 것 |
| a tier list | 티어 리스트 — S/A/B/C 로 매긴 우선순위 |
| slot time | 슬롯 시간 — 블록 하나에 배정된 시간 |
| an attestation deadline | 어테스테이션 마감 — 투표가 유효한 시한 |
| time-to-finality | 최종성까지의 시간 — 되돌릴 수 없게 되기까지 |
| justification | (합의에서) 정당화 — 최종성 직전 단계의 투표 라운드 |
| to compound | 복리로 붙다 — 효과가 곱해지며 커지다 |
| a polling interval | 폴링 주기 — 확인하러 가는 간격 |
| to sit unprocessed | 처리되지 않은 채 있다 — 이미 참인데 아무도 안 읽은 상태 |
| succinct proof | 간결 증명 — 작고 빨리 검증되는 증명 |
| formal verification | 형식 검증 — 수학적으로 속성을 증명하는 것 |
| an adoption gate | 도입 관문 — 그것이 움직여야 나머지가 움직이는 지점 |
| the last mile | 마지막 한 구간 — 사용자에게 닿는 마지막 단계 |
| to trace something through | ~를 끝까지 따라가 보다 — 설계 검증의 방법 |
| a persona | 페르소나 — 가상의 대표 사용자 |
| a user story | 사용자 스토리 — "~로서 ~하고 싶다" 형태의 요구 기술 |
| unclear expectations | 불분명한 기대 — 명시되지 않아서 생기는 제약 |
| to plan against uncertainty | 불확실성을 상대로 계획하다 — 대개 보수적으로 잡게 된다 |
| work in progress | 진행 중 — 결과로 인용하면 안 되는 것 |
