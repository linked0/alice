| Expression | 뜻 · 쓰이는 자리 |
|---|---|
| vacuously true | 공허하게 참인(전제가 거짓이라 자동으로 참인) · 조건문에서 전제가 거짓일 때 결론과 무관하게 참이 되는 논리 개념. "vacuously true whenever p is false" |
| contrapositive | 대우(명제) · 원명제와 항상 논리적으로 같은 값을 갖는 형태. "its contrapositive ¬q→¬p is always logically equivalent" |
| swap when negated | 부정될 때 서로 자리를 바꾸다 · 전칭·존재 한정사가 부정문에서 뒤바뀔 때. "the quantifiers ∀ and ∃ swap when negated" |
| disjoint | 서로 겹치지 않는 · 집합들이 공통 원소가 없을 때. "disjoint equivalence classes" |
| the basis for | ~의 기반이 되다 · 어떤 개념이 다른 개념을 성립시키는 토대일 때. "the basis for comparing sizes" |
| translate back into | 다시 옮기다(기호를 문장으로) · 수식·기호를 원래 의미로 되돌려 이해할 때. "translating symbols back into sentences" |
| formalize | 명제를 논리 기호로 정형화하다 · 자연어 문장을 기호 논리로 표현할 때. "using quantifiers and logical connectives" |
