| Expression | 뜻 · 쓰이는 자리 |
|---|---|
| a regulatory sandbox | 규제 샌드박스 — 한시적으로 규제를 면제하고 실증하게 하는 제도 |
| a demonstration exemption | 실증특례 — 샌드박스가 내주는 면제. 영어 기사에서는 regulatory exemption 도 쓴다 |
| to grant an exemption | 특례를 내주다 — 주체는 규제 당국. "the sandbox granted six banks an exemption" |
| held in writing | 서면으로 개최된 — 회의체가 모이지 않고 문서로 의결할 때 |
| a deposit token | 예금토큰 — 은행 예금을 근거로 발행되는 토큰. 가상자산과 구분해서 쓴다 |
| office running costs | 관서운영경비 — 정부 부처의 운영 경비. 업무추진비가 그 일부 |
| a procurement card | 구매카드 — 조직이 지출용으로 발급하는 법인카드 |
| a merchant category code (MCC) | 가맹점 업종코드 — 카드망이 업종을 식별하는 번호 |
| to preset something | 미리 설정해 두다 — "the hours and categories are preset on the token" |
| at issuance | 발행 시점에 — 대비되는 말은 at authorisation(승인 시점), after the fact(사후) |
| after the fact | 사후에 — 감사·적발을 말할 때 거의 관용구 |
| the control surface | 통제 지점·통제면 — 어디에서 규칙이 걸리는가. 보안·설계 문서의 말 |
| programmable money | 프로그래머블 머니 — 조건을 코드로 붙일 수 있는 돈 |
| a seat of power | 권력이 앉는 자리 — 추상적 권한이 실제로 어디에 있는지 |
| the float | 플로트 — 결제와 정산 사이에 떠 있는 자금·기간 |
| a chargeback | 지급거절·결제취소 — 카드 수수료를 구성하는 비용 중 하나 |
| the acquiring side | 매입사 쪽 — 가맹점을 유치·관리하는 쪽 |
| to carry the burden | 부담을 지다 — "small merchants carry less burden" |
| plausible but unpriced | 그럴듯하지만 값이 안 붙은 — 숫자 없는 주장에 붙이는 말 |
| to take something off the balance sheet | 대차대조표에서 빼다 — 청구권이 어디 있는지 말할 때 |
