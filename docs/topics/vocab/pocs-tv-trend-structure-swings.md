| Expression | 뜻 · 쓰이는 자리 |
|---|---|
| swing high / swing low | 스윙 고점 / 스윙 저점(앞뒤 봉보다 높거나 낮은 지점) · 구조 읽기의 최소 단위. "A swing high is a bar, or a small cluster of bars, whose high sits above the highs immediately before and after it" |
| higher high (HH) | 고점 갱신(이전 고점보다 높은 새 고점) · 상승 추세를 이루는 절반의 조건. "Each high above the prior high" |
| higher low (HL) | 저점 갱신(이전 저점보다 높은 새 저점) · 상승 추세의 나머지 절반. "the most recent higher low" |
| lower high (LH) / lower low (LL) | 고점·저점 둘 다 낮아짐 · 하락 추세의 정의. "LH, LL — Downtrend" |
| break of structure (BOS) | 구조 붕괴(추세 시퀀스를 깨는 새 스윙) · 되돌림과 구별되는 핵심 개념. "A break of structure (often shortened BOS) is different in kind, not degree" |
| pullback | 되돌림(마지막 스윙을 존중하는 일시적 반대 움직임) · BOS와 짝지어 자주 헷갈리는 개념. "A pullback is a retracement that still respects the last confirmed swing" |
| retracement | 되돌림·조정 · pullback의 동의어로 정의문에 사용. "A pullback is a retracement that still respects" |
| trendline | 추세선 · 두 번 터치로 긋고 세 번째로 확정. "A trendline needs two touches to draw" |
| `Parallel Channel` | 평행 채널 도구(추세선 + 자동 평행선) · TradingView 그리기 도구 이름, 코드 표기 유지. "draw the base trendline, then set a second, parallel line" |
| `Ray` | 레이(한쪽 방향으로만 무한 연장되는 선 도구) · 레벨을 앞으로 투영할 때. "only extends infinitely in one direction" |
| `Pitchfork` | 피치포크(범위 밖으로 남겨둔 고급 도구) · 이번 항목에서는 의도적으로 skip. "it is out of scope here; skip it for now" |
| `Replay` | 리플레이(과거 시점부터 봉 단위로 재생하는 연습 도구) · 사후 확신 없이 구조 읽기 연습. "step forward bar by bar" |
| regime | 국면(추세냐 레인지냐 하는 시장 상태 분류) · Number 리딩에 태그로 붙이는 개념. "carry a one-word regime tag, trend or range" |
| falsifiable | 반증 가능한(맞았는지 틀렸는지 확인할 수 있는) · 다우 정의를 "느낌"과 구분하는 말. "Dow's definition is mechanical and falsifiable" |
| rule of thumb | 경험칙(엄밀한 규칙이 아니라 실무 감각) · 이 항목의 미확인 항목 표시어. "A workable rule of thumb" |
| realized volatility | 실현 변동성(실제로 관측된 가격 변동폭) · 레인지·추세 국면 비교에 사용. "typically shows lower realized volatility than a trending one" |
| VaR | Value at Risk, 특정 확률로 예상되는 최대 손실 추정치 · Theory 항목과 연결되는 리스크 지표. "a VaR figure estimated during a range regime can understate risk" |
| RSI / MACD | 상대강도지수 / 이동평균수렴확산지수(대표적인 모멘텀 지표) · 국면 태그 없이 쓰면 오독되는 예. "the same RSI or MACD reading means something different in each" |
