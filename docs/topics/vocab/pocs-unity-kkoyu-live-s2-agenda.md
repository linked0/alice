|---|---|

| to converge on X | X로 수렴하다 · "the renderer converges on URP" |
| a migration in disguise | 실은 마이그레이션(다른 이름을 달고 있을 뿐) · 세션 넷의 정체 |
| a deprecation notice | 지원 종료 공지 · "one renderer is a deprecation notice written politely" |
| take rate | 테이크레이트(플랫폼이 가져가는 수수료 비율) · 결제·마켓플레이스 논의의 핵심 숫자 |
| the platform cut | 플랫폼 수수료(플랫폼 몫) · take rate의 일상 표현 |
| a line item | (예산·정산서의) 개별 항목 · "the largest single line item in the revenue split" |
| to deep-link (players) out to X | 딥링크로 X까지 내보내다 · 게임 안에서 웹샵으로 보내는 동작 |
| link-out policy | 링크아웃 정책(앱 밖 결제로 보내는 것에 대한 스토어 규칙) |
| plumbing | 배관(눈에 안 보이지만 실제로 연결해야 하는 부분) · 팀이 늘 과소평가하는 일 |
| on by default / off by default | 기본 켜짐 / 기본 꺼짐 · 기본값이 논증의 전부가 되는 자리 |
| observability debt | 관측 가능성 부채(측정을 안 해 둬서 나중에 갚는 비용) |
| to backfill (data) | 소급해서 채우다 · "cannot be backfilled" — 장애 직전 데이터가 없는 이유 |
| frame budget | 프레임 예산(한 프레임에 쓸 수 있는 시간) · 최적화 대화의 단위 |
| thermals | 발열(기기가 뜨거워져 성능이 깎이는 문제) |
| a profiling partner | 프로파일링 파트너 · AI를 도구가 아니라 짝으로 부르는 표현 |
| on-device inference | 온디바이스 추론(서버가 아니라 기기 안에서 모델을 돌리는 것) |
| the command surface | 명령 표면(에이전트가 부를 수 있는 명령의 전체) · "an agent is only as good as the command surface it is given" |
| to close the loop | 루프를 닫다(제안에서 끝내지 않고 실행·검증까지 가다) |
| a cheaper signal | 더 싼 신호(적은 비용으로 같은 정보를 주는 것) · 키노트 대신 아젠다를 읽는 이유 |
