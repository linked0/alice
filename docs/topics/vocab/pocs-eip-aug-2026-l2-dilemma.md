| Expression | 뜻 · 쓰이는 자리 |
|---|---|
| a privileged set | 특권적 집합 — 남들이 못 하는 일을 할 수 있는 소수. 탈중앙화 논의의 핵심어 |
| to spread the load | 부담을 분산하다 — 한 주체에 몰린 일을 여럿에게 |
| to inherit security | 보안을 상속하다 — L2가 L1에서 물려받는다고 주장하는 것 |
| a maturity framework | 성숙도 프레임워크 — L2BEAT 의 Stage 0~2 같은 단계 척도 |
| to challenge an invalid state | 잘못된 상태에 이의를 제기하다 — 옵티미스틱 롤업의 핵심 권리 |
| a forced inclusion | 강제 포함 — 시퀀서를 거치지 않고 L1으로 거래를 밀어 넣는 것 |
| an upgrade delay | 업그레이드 지연 — 바꾸기 전 기다려야 하는 기간. 0이면 경고 신호 |
| a security council | 보안위원회 — 소수 서명으로 시스템을 바꿀 수 있는 조직 |
| trust minimization | 신뢰 최소화 — 사람 대신 코드가 보증하게 만드는 방향 |
| self-sovereignty | 자기주권 — 운영자 협조 없이도 거래·출금할 수 있는 상태 |
| data availability | 데이터 가용성 — 데이터가 공개되어 있어 상태를 재구성할 수 있음 |
| to accrue to someone | ~에게 귀속되다 — "growth does not accrue to Ethereum" |
| value capture | 가치 포착 — 만들어진 가치 중 누가 얼마를 가져가는가 |
| a fee market | 수수료 시장 — 블록 공간을 두고 값이 정해지는 곳 |
| a priority fee | 우선순위 수수료 — 먼저 처리되려고 더 내는 금액. 없으면 기본료가 다 올라간다 |
| a bottleneck | 병목 — 전체 속도를 정하는 가장 좁은 지점 |
| structural, not technical | 구조의 문제이지 기술의 문제가 아니다 — 논쟁을 정리하는 문장 |
| to be at odds with | ~와 상충하다 — "trust minimization is at odds with regulated operation" |
| a rung on the ladder | 사다리의 칸 — 단계 척도를 말할 때 |
| an intended outcome | 의도된 결과 — 버그가 아니라 설계대로. "cheap blobspace is an intended outcome" |
| to be counted as | ~로 계산되다 — "L2 volume cannot be counted as value accruing to Ethereum" |
