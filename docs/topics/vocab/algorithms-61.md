| Expression | 뜻 · 쓰이는 자리 |
|---|---|
| withhold | 보류하다, 내주지 않고 감추다 · 생산자가 데이터 조각을 숨긴다는 뜻. "the producer must withhold a substantial fraction" |
| drive down | 수치를 끌어내리다 · 표본 수를 늘려 확률을 낮춘다는 뜻. "drives the probability of missing that unavailability down exponentially" |
| probabilistically | 확률적으로 · 전체를 확인하지 않고도 확률로 검증한다는 뜻. "verify that probabilistically without running a full node" |
| trust assumptions | 신뢰 전제 · 시스템 설계가 무엇을 믿고 있는지에 대한 가정. "the trust assumptions behind any service built on an L2" |
| hand out | 나눠서 내주다, 배포하다 · 조각 데이터를 나눠준다는 뜻. "the producer could hand out pieces that were encoded incorrectly" |
| exploit | 특성을 이용하다, 활용하다 · 어떤 속성을 역으로 활용해 검증한다는 뜻. "Data availability sampling (DAS) exploits this" |
