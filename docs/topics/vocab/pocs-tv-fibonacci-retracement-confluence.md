| Expression | 뜻 · 쓰이는 자리 |
|---|---|
| retracement | 되돌림(추세 중 일시적 역방향 움직임) · extension(확장)과 짝을 이루는 핵심 용어. "A Fibonacci retracement is a pullback ruler" |
| swing low / swing high | 스윙 저점 / 스윙 고점(국지적 최저·최고 캔들) · 피보 도구를 고정하는 두 앵커. "drag from the swing low to the swing high" |
| anchor | 앵커, 고정점(드로잉 도구를 붙잡아 두는 기준점) · 동사로도 쓰임. "The tool only means something once it is anchored correctly" |
| golden pocket | 골든 포켓(38.2%~61.8% 구간의 별칭) · 되돌림 매수/매도를 노리는 구간 이름. "The zone between 38.2% and 61.8% is nicknamed the golden pocket" |
| extension | 확장(100% 너머로 투영한 레벨) · 목표가 산정에 쓰임. "Extensions use the same anchor points to project levels beyond 100%" |
| confluence | 컨플루언스(여러 신호가 같은 지점에서 겹치는 것) · 레벨 단독이 아니라 다른 증거와 겹칠 때 신뢰도가 오른다는 개념. "before acting is the difference between using the tool and being used by it" |
| self-fulfilling prophecy | 자기실현적 예언(많은 사람이 믿어서 실제로 이루어지는 현상) · 피보 레벨이 "작동하는" 이유의 대표 설명. "The self-fulfilling-prophecy explanation for why Fibonacci levels sometimes work" |
| rule of thumb | 경험칙, 어림 규칙(엄밀한 증명 없이 통하는 관행) · 확실하지 않은 것을 표시할 때 쓰는 표현. "treat it as a heuristic worth checking" |
| magnet mode | 마그넷 모드(그리기 도구 앵커를 가까운 가격에 스냅시키는 기능) · TradingView 하단 도구모음 아이콘. "Turn on magnet mode first, the magnet icon near the bottom" |
| pullback | 풀백(추세 중 조정 하락/상승) · retracement와 거의 동의어로 쓰임. "a pullback commonly reaches before the prior move resumes" |
| structure | 구조(스윙 고점·저점이 만드는 차트의 골격) · 되돌림 레벨을 확인하는 대표적 근거. "confirm with structure or a moving average" |
| flyout group | 플라이아웃 그룹(아이콘을 누르고 있으면 펼쳐지는 하위 도구 목록) · Trend-Based Fib Extension을 찾는 UI 동작. "click and hold the Fib Retracement icon to open the flyout group" |
| reference rate | 참조 금리/기준가(관리자·픽싱 시각·방법론이 있는 공식 가격) · Verex 정산 맥락에서 피보 레벨과 대비되는 개념. "should name a benchmark or a specific venue price" |
| falsifiable | 반증 가능한(참/거짓을 검증할 수 있는) · Auditor 항목에서 앵커 기록의 필요성을 설명할 때. "Price respected the golden pocket is unfalsifiable without recording..." |
| distribution | 분포(통계에서 값들이 퍼진 형태) · "50% pullback" 통설을 통계로 재해석할 때. "a claim about the distribution of pullback-to-swing ratios" |
| candidate target | 후보 목표(확정 계획이 아닌 여러 가능성 중 하나) · 확장 레벨을 다루는 태도. "treat one as a candidate target, not a plan" |
