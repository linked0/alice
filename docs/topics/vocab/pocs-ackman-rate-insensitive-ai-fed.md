| Expression | 뜻 · 쓰이는 자리 |
|---|---|
| **rate-insensitive demand** | 금리에 둔감한 수요. 통화정책 논의의 핵심 용어 |
| **monetary transmission** | 통화(정책) 전달 경로. 금리가 실물에 닿는 경로 |
| **a two-speed economy** | 이중 속도 경제. 한쪽은 과열, 한쪽은 침체 |
| **flip the sign** | 부호를 뒤집다. 효과의 방향이 반대가 된다는 뜻 |
| **load-bearing** | 하중을 받는. "the load-bearing member of the argument" = 논증을 떠받치는 항 |
| **unfalsifiable** | 반증 불가능한. 검증할 수 없어 반박도 안 되는 주장 |
| **the burden sits with ~** | 입증 책임은 ~에게 있다 |
| **pass-through** | 전가(轉嫁). 비용 상승분이 가격으로 넘어가는 비율 |
| **cost share** | 비용에서 차지하는 몫 |
| **duration** (금융) | 듀레이션. 현금흐름이 얼마나 먼 미래에 있는가 — 길수록 금리에 민감 |
| **a premise with an expiry date** | 유효기간이 있는 전제 |
| **it is a policy-cost story, not a sign-flip story** | 정책 비용 이야기지 부호 전환 이야기가 아니다 |
| **over-tighten** | 과도하게 긴축하다 |
| **supply shock** | 공급 충격. 금리로는 고칠 수 없는 종류 |
