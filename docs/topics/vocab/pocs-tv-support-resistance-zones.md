| Expression | 뜻 · 쓰이는 자리 |
|---|---|
| zone | 구간(선이 아니라 폭이 있는 가격대) · 이 항목 전체의 핵심 개념. "Treat a level as a zone spanning a handful of ticks or a percent, not a single line" |
| swing high / low | 스윙 고점·저점(국지적 반전 지점) · 레벨을 찾는 첫 번째 방법. "**Swing highs and lows**: local peaks and troughs where price visibly reversed" |
| round number | 라운드 넘버(둥근 숫자, 심리적 가격) · 사람들이 무의식적으로 모이는 가격. "**Round numbers**: psychological levels like $100 or 4.000" |
| high-volume close | 거래량이 큰 종가 · 볼륨 프로파일로 확인하는 레벨의 세 번째 근거. "**High-volume closes**: prices where heavy volume traded and candles closed" |
| role flip / role reversal | 역할 뒤집기(지지↔저항) · 구간이 깨진 뒤의 표준 행동. "its role often flips: broken support becomes resistance" |
| self-fulfilling | 자기실현적인 · 많이 주목받아서 실제로 작동하는 현상을 부를 때. "attention is somewhat self-fulfilling" |
| resting order | 대기 주문(아직 체결 안 된 지정가 주문) · 구간이 시험받을 때마다 소진되는 것. "each approach fills or cancels resting orders" |
| break and retest | 돌파-리테스트(돌파 후 같은 구간을 재시험) · 진입 확인 패턴 이름. "A break and retest is the classic confirmation" |
| false break / fakeout | 가짜 돌파 · 꼬리만 뚫고 종가는 원래 쪽으로 닫히는 경우. "A false break (fakeout) is a wick through the zone within one candle that closes back on the original side" |
| on a closing basis | 종가 기준으로 · 꼬리가 아니라 캔들 마감가로 판단한다는 뜻. "When a zone breaks on a closing basis, roles reverse" |
| magnet mode | 마그넷 모드(드로잉을 캔들 값에 자동으로 붙여주는 기능) · 트레이딩뷰 툴바 아이콘. "Magnet mode: the toolbar's magnet icon snaps a point to the nearest OHLC value" |
| OHLC | 시가·고가·저가·종가(Open-High-Low-Close) · 캔들 하나가 담는 네 가격. "the nearest `OHLC` value in view" |
| ATR | 평균 실질 변동폭(Average True Range) · 구간 폭과 스탑 거리를 잡는 변동성 척도. "sized by recent volatility (`ATR`)" |
| R:R | 손익비(risk-to-reward ratio) · 스탑과 목표 거리의 비율. "a workable risk-to-reward (`R:R`) plan" |
| HTF | 상위 타임프레임(Higher Time Frame) · 더 무겁게 취급하는 큰 그림 차트. "A level on a higher timeframe (`HTF`), say a weekly swing low" |
| LTF | 하위 타임프레임(Lower Time Frame) · HTF와 짝지어 쓰는 작은 차트. "the same price noticed only on a lower timeframe (`LTF`) chart" |
| Crossing (alert) | "크로싱" 조건(가격이 그 라인을 지나갈 때 발동) · 트레이딩뷰 알림 조건 이름. "condition `Crossing` (or `Crossing Up`/`Down`)" |
| Horizontal Ray | 수평 레이(클릭한 지점부터 오른쪽으로만 뻗는 선) · Horizontal Line과 구분되는 도구. "`Horizontal Ray`: extends only rightward from the clicked point" |
