| Expression | 뜻 · 쓰이는 자리 |
|---|---|
| roof (of an argument) | 지붕(논증의 최종 논지) · 3단 구조의 최상위층을 가리키는 이 항목의 핵심 비유. "a roof (the final thesis)" |
| pillar | 기둥(핵심 논거) · 지붕을 떠받치는 3~4개의 근거. "three or four pillars" |
| foundation (of an argument) | 기단(논증을 성립시키는 전제) · 무너지면 전체가 무너지는 밑바탕. "the premise that makes the pillars possible" |
| load-bearing | 하중을 지탱하는 · 어떤 전제·요소가 없으면 구조 전체가 무너진다는 뜻의 비유. (건축 비유를 뒷받침하는 표현) |
| superordinate categorization | 상위 범주화(지엽적 서술을 상위 개념으로 묶는 것) · 세 기술 중 첫째. "pulling scattered statements into a higher category" |
| paraphrase (v./n.) | 패러프레이징(원문 어휘에 얽매이지 않고 자기 언어로 재진술) · 세 기술 중 둘째. "paraphrasing the gist in their own words" |
| MECE | Mutually Exclusive, Collectively Exhaustive(상호 배타적이고 전체를 포괄하는) · 민토식 기둥 구성의 원칙. "MECE (mutually exclusive, collectively exhaustive) pillars" |
| Pyramid Principle | 피라미드 원칙(결론 먼저, 근거는 MECE로) · 바바라 민토가 정리한 맥킨지의 글쓰기 표준. "Barbara Minto's *The Pyramid Principle*" |
| premise | 전제(논증이 성립하기 위해 참이어야 하는 가정) · 기단과 사실상 같은 개념. "the premise the roof depends on" |
| macrorules | 거시규칙(텍스트를 요약할 때 쓰는 삭제·일반화·구성 규칙) · 킨취·반 다이크의 독서 이해 이론 용어. "Kintsch and van Dijk's macrorules" |
| deletion / generalization / construction | 삭제 / 일반화 / 구성 · 거시규칙을 이루는 세 조작. "deletion, generalization, construction" |
| retention | (기억) 유지 · 읽은 내용이 실제로 남는 정도, 앤드류 응이 강조한 지표. "Andrew Ng's retention point" |
| intersection (of statements) | 교집합(여러 서술이 공유하는 공통 부분) · 상위 범주화의 재료. "scattered statements share an intersection" |
| hierarchy | 위계(상위-하위 관계) · 명제들을 주종 관계로 배열하는 것. "arranging the resulting propositions into a hierarchy" |
| thesis | 논지(글이 주장하는 핵심 명제) · 지붕과 사실상 동의어. "the final thesis" |
| grading rubric | 채점 기준(항목을 평가하는 명시적 규칙 목록) · 지붕-기둥-기단 점검을 이렇게 쓰자는 제안. "a grading rubric" |
| clean, on-purpose (line) | 의도적으로 명시한 (한 줄) · 암묵적 가정을 일부러 드러내 쓰는 태도. "stated on purpose instead of left for the reader to reconstruct" |
| Minto order | 민토 순서(결론 먼저, 그다음 근거) · Eng 섹션의 면접 답변 형식으로 제안. "answer interview questions in Minto order" |
| cause-effect machine | 인과 기계(현상을 일으키는 원인-결과 메커니즘) · 레이 달리오가 거시 현상을 설명할 때 쓰는 틀. "core principles and cause-effect machines" |
| flat list | 평면적 나열(위계 없이 항목을 죽 늘어놓은 것) · 위계 재구성이 없는 상태, 기단이 없는 경우와 대비. "a flat list of unrelated facts" |
