| Expression | 뜻 · 쓰이는 자리 |
|---|---|
| stop-loss (stop) | 손절(가격이 닿으면 자동으로 포지션을 정리하는 주문) · 이 글 전체의 핵심 개념. "A stop-loss placed at a round number" |
| structure | (차트) 구조 — 스윙·지지/저항처럼 차트 스스로 정의하는 레벨 · "where a chart's structure actually breaks" |
| swing low / swing high | 스윙 저점 / 고점(가격이 가장 최근에 방향을 튼 지점) · "a swing low or swing high" |
| support / resistance zone | 지지 / 저항 구간(두 번 이상 반전이 나온 가격대) · "a support or resistance zone" |
| rule of thumb | 경험칙, 엄밀한 법칙이 아닌 관행적 기준 · "usually 1% as a rule of thumb" |
| position size | 포지션 크기(수량) · "position size is no longer a guess" |
| account risk | 계좌 위험(계좌 대비 감수하기로 한 손실 비율) · "risk a small, fixed percent of the account" |
| 1R / R-multiple | 위험 1단위, 손익을 위험의 배수로 표현하는 단위 · "The unit of risk on that trade is called 1R" |
| reward-to-risk (R:R) | 손익비, 목표까지 거리 대 손절까지 거리 · "a 1:2 reward-to-risk at a 40% win rate" |
| expectancy | 기댓값, 여러 거래에 걸친 거래당 평균 R 손익 · "expectancy, the average R gained or lost per trade" |
| breakeven win rate | 손익분기 승률(그 이상이면 시스템이 이익) · "the breakeven win rate at a 1:2 reward-to-risk is 33.3%" |
| stop hunt / liquidity sweep | 스탑 헌트 / 유동성 스윕(레벨을 살짝 넘었다 되돌리는 가격 움직임) · "known loosely as a stop hunt or liquidity sweep" |
| invalidate / invalidation | 무효화(아이디어가 틀렸다고 확정되는 지점) · "tests whether the trade idea itself failed" |
| Long Position / Short Position (tool) | TradingView에서 진입·목표·손절과 R:R, 수량을 함께 그려주는 도구 · "the `Long Position` tool (or `Short Position` for shorts)" |
| Crossing | 알림 조건 중 하나, 가격이 선을 가로지를 때 · "set the condition to `Crossing`" |
| Once Per Bar Close | 알림 빈도 설정, 봉이 마감될 때만 트리거 · "set the trigger to `Once Per Bar Close`" |
| Bar Replay | 과거 데이터를 봉 단위로 재생해 연습하는 TradingView 모드 · "Practice the whole workflow risk-free in `Replay` mode" |
| journal (a trade) | 거래를 기록하다(계획과 결과를 남겨 나중에 복기) · "journal each one's planned stop, target, R:R and outcome" |
