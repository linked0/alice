| Expression | 뜻 · 쓰이는 자리 |
|---|---|
| **a door into** something | ~로 들어가는 입구. 큰 대상에 접근하는 구체적 경로를 말할 때. "the 23 doors into the canon" |
| **clear** a filter / a bar | 조건을 통과하다. 기준을 넘다. 시험·심사·요건 문맥 전부에 쓰임 |
| **query** a list | 목록에 질의하다. DB 용어를 일상 대상에 쓰는 흔한 확장 — "a ranking cannot be queried that way" |
| **entry condition** | 진입 조건. 무엇을 시작하기 위해 충족돼야 하는 상태 |
| **state of mind** | 마음 상태. "about the object vs. about the state of mind"처럼 대비할 때 자주 |
| **a prestige-versus-usefulness split** | 권위 대 실용의 대립 구도. X-versus-Y를 형용사처럼 통째로 붙여 쓰는 조어법 |
| **run down / work down** a list | 목록을 위에서부터 훑어 내려가다 |
| **a guest on** the list | 목록의 손님 — 곁다리로 끼어 있다는 뜻. 부정형으로 쓰면 "본진이다"라는 강한 주장 |
| **reverse-engineer** a rule | 결과물에서 규칙을 역으로 추론하다 |
| **survive a change of mood** | 분위기가 바뀌어도 살아남다. 선택지의 견고함을 말하는 관용적 표현 |
| **nothing rests on** X | X에 걸린 주장이 없다. 근거가 약한 수치를 쓸 때 면책하는 정확한 표현 |
| **filed as** a thriller | 스릴러로 분류된. file A as B = A를 B로 분류·정리하다 |
