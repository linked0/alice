|---|---|
| co-opt (verb) | 원래 목적이 다른 것을 가져다 쓰다 · 뇌가 기존 영역을 새 용도로 전용할 때. "the brain co-opts regions built for something else" |
| neuronal recycling | 신경 재활용(기존 회로를 새 기능에 재사용한다는 Dehaene의 이론) · 읽기 회로 형성의 표준 설명. "Stanislas Dehaene's 'neuronal recycling' theory" |
| visual word form area (VWFA) | 시각 단어 형태 영역(문자를 시각적으로 인식하는 뇌 부위) · 읽기 신경과학의 핵심 용어. "the visual word form area" |
| plastic / plasticity | 가소적인 / 가소성(경험에 따라 구조가 바뀌는 성질) · 읽기가 뇌 구조 자체를 바꾼다는 주장의 핵심어. "the resulting network is plastic" |
| orthography | 표기법(문자 체계, 철자 체계) · 문자 체계별로 다른 읽기 회로를 가리킬 때. "different orthographies build partly separate networks" |
| morpheme | 형태소(의미를 가진 가장 작은 언어 단위) · 한자가 소리가 아니라 형태소에 대응한다는 설명에서. "map to whole morphemes rather than sounds" |
| biscriptal | 두 문자 체계를 함께 쓰는(사람) · 뇌졸중 환자가 한 문자만 잃은 사례를 가리키는 말. "differential alexia in biscriptal (two-script) patients" |
| alexia | 실독증(후천적으로 읽기 능력을 잃는 증상) · 뇌 손상 이후 읽기 상실을 가리키는 의학 용어. "differential alexia" |
| lesion | 병변(뇌졸중 등으로 손상된 부위) · 신경심리학에서 손상-기능 상관관계를 논할 때. "losing one script while keeping another after a lesion" |
| anterior insula | 전측 뇌섬엽(위장 감각·통증·공감을 함께 처리하는 뇌 영역) · 소설을 읽을 때 신체 반응이 나오는 이유. "the anterior insula, a region that processes gastric sensation" |
| interoception | 내수용감각(몸 내부 상태를 느끼는 감각, 예: 배고픔·메스꺼움) · 뇌섬엽의 핵심 기능. "the anterior insula's role in interoception" |
| embodied (empathy) | 몸으로 구현된 (공감) · 소설 속 감정이 실제 신체 반응으로 나타나는 현상을 가리킴. "Fiction's empathy effect is not metaphorical" |
| executive function | 실행 기능(계획·억제·전환 등 상위 인지 조절 능력) · 스크린 시간과 아동 발달 연구의 핵심 측정치. "lower attention, executive function and academic achievement" |
| critical thinking | 비판적 사고(정보를 평가하고 판단하는 능력) · 훑어 읽기가 약화시킨다고 주장되는 능력. "weakening critical thinking" |
| skimming | 훑어 읽기(빠르게 핵심만 보는 읽기 방식) · 이 항목에서 깊이 읽기와 대비되는 읽기 방식. "skimming is described as weakening critical thinking" |
| deep reading | 깊이 읽기(구조를 따라가며 몰입해서 읽는 방식) · 훑어 읽기의 반대, 이 항목의 해법. "a life built around deep reading rewires the brain" |
| boredom tolerance | 지루함 내성(자극 없는 시간을 견디는 능력) · 스크린이 낮춘다고 주장되는 능력, 지속적 읽기의 전제조건. "boredom tolerance is exactly what sustained reading requires" |
| correlational (vs causal) | 상관관계의 (인과관계와 대비) · 스크린 시간-발달 연구를 과대 해석하지 않기 위한 구분. "a correlation, not shown here as causation" |
| cuneiform | 쐐기문자(수메르의 초기 문자 체계) · 문자가 진화적으로 최근임을 보여주는 예. "Sumerian cuneiform, roughly 3300 BCE" |
