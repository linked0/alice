| Expression | 뜻 · 쓰이는 자리 |
|---|---|
| **the cut line** | 커트라인. 합격/선정 경계. "where a list was cut"처럼 동사로도 |
| **the near misses** | 아깝게 떨어진 것들. 순위·심사·채용 전부에 쓰임 |
| **a one-vote-wide boundary** | 한 표 폭의 경계. 경계가 얼마나 얇은지 강조하는 조어 |
| **made visible** | 드러나게 된. 숨어 있던 것이 보이게 될 때 — "a boundary made visible" |
| **a settled canon** | 확정된 정전. settled = 논쟁이 끝난, 굳어진 |
| **recency is visible in the data** | 최신 편향이 데이터에 드러난다. 설문·랭킹 분석에서 바로 쓸 수 있는 문장 |
| **calibration instrument** | 보정 도구. 다른 것을 재기 위한 기준으로 삼는 대상 |
| **read half of it** | 절반만 읽은 것이다. 불완전한 이해를 지적하는 관용 표현 |
| **correct to its own question** | 자기 질문에는 맞다. 둘 다 틀리지 않았다고 말할 때의 정확한 표현 |
| **a medium's foundations** | 한 매체의 토대. medium = 매체(복수 media) |
| **nowhere in the top 50** | 50위 안에 아예 없다. nowhere in ~ = ~ 안 어디에도 없다 |
| **it shows** | 티가 난다. "This is a 2006 list and it shows." — 앞 문장의 근거가 눈에 보인다는 뜻 |
