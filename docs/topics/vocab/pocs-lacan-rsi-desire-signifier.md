| Expression | 뜻 · 쓰이는 자리 |
|---|---|
| mirror stage | 거울 단계(생후 6~18개월, 유아가 거울 속 통일된 이미지를 자기로 오인하는 시기) · 상상계 형성의 핵심 개념. "The Imaginary starts at the mirror stage, 6–18 months" |
| RSI (Real, Symbolic, Imaginary) | 실재계·상징계·상상계(라캉의 세 위상, 프로이트의 이드/자아/초자아를 대체) · 이 항목 전체의 뼈대. "Lacan proposes three registers instead" |
| misrecognition | 오인(자신이 아닌 것을 자신으로 착각) · 거울 단계 이론의 핵심 동작. "misrecognizes it as itself" |
| closed dyad | 닫힌 이인관계(둘만의 폐쇄된 관계, 여기선 유아-어머니) · 상상계가 상징계로 열리기 전 상태. "a closed two-person world with the mother" |
| Name-of-the-Father (Nom-du-père) | 아버지의-이름(생물학적 아버지가 아니라 법·언어·질서의 자리) · 상징계 진입의 매개. "the position of law and language that intervenes" |
| symbolic castration | 상징적 거세(어머니를 완성하는 존재가 되려는 환상을 포기하는 것) · 주체 형성의 대가로 받아들이는 결여. "accepting a permanent lack at the center of the self" |
| signifier / signified | 기표(소리·형태) / 기의(개념·의미) · 소쉬르 기호론의 두 축, 라캉이 우선순위를 뒤집는 지점. "the signifier moves and the signified slides under it" |
| S/s bar | S/s 바(라캉이 기표 S를 기의 s 위에 쓰고 선을 그은 표기) · 기표 우위를 나타내는 라캉 고유 표기. "Lacan writes it as a bar, S over s" |
| condensation | 압축(여러 생각이 하나의 이미지로 눌려 담기는 꿈 기제) · 은유와 대응. "condensation — many ideas compressed into one image" |
| displacement | 전치(의미가 인접 요소로 미끄러지는 꿈 기제) · 환유와 대응. "displacement — significance sliding from one element to an adjacent one" |
| metaphor / paradigm | 은유 / 계열체(수직축의 대체) · 압축의 언어학적 대응. "is paradigm/metaphor, substitution along a vertical axis" |
| metonymy / syntagm | 환유 / 통합체(수평·순차축의 대체) · 전치의 언어학적 대응. "is syntagm/metonymy, substitution along the horizontal" |
| desire of the Other | 타자의 욕망(원함이 타자가 원하는 것을 거쳐 간다는 라캉의 공식) · "man's desire is the desire of the Other". "wanting is routed through what we imagine the other wants from us" |
| demand vs need | 요구 대 필요(말해진 요구는 순수한 필요를 넘어선다) · 욕망 공식의 두 변수. "asking for milk is also, always, asking to be loved unconditionally" |
| structural gap/remainder | 구조적 간극/잉여(대상으로 메울 수 없는 남는 부분) · 욕망을 정의하는 핵심 성질. "a structural remainder no specific object fills" |
| return to Freud | 프로이트로의 회귀(라캉이 자신의 기획을 부르는 이름) · 언어학으로 프로이트를 재해석하는 프로젝트 전체. "his 'return to Freud'" |
| Ding an sich | 물자체(칸트, 경험으로 포착되지 않는 사물 그 자체) · 라캉의 실재계를 설명할 때 끌어온 비유. "comparable to ... Kant's Ding an sich" |
| structured like a language | 언어처럼 구조화된(무의식의 형식을 규정하는 라캉의 명제) · 프로이트의 무의식 개념을 확장. "the unconscious is structured like a language" |
| through line | 관통선(여러 항목을 꿰는 하나의 일관된 줄기) · 욕망을 채우는 대신 방향을 잡는 방법. "pick a through line and a filing system" |
| filing system | 정리 체계(들어온 것을 어디에 둘지 정하는 규칙) · through line과 짝을 이루는 실무적 해법. "not more input" |
| bid for recognition | 인정을 얻으려는 시도(필요로 위장한, 실은 타자를 향한 요구) · 소비·학력 경쟁을 읽는 틀. "bids for recognition through an Other, dressed as needs" |
