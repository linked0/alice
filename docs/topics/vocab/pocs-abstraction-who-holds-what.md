| Expression | 뜻 · 쓰이는 자리 |
|---|---|
| abstraction | 추상화 — 복잡성을 사용자 눈앞에서 치우는 것. "a transfer, not a deletion" |
| onboarding | 신규 사용자 진입 과정 — "the onboarding barrier", "compressed into a single login" |
| a recovery phrase / seed phrase | 복구구문 — 지갑 복구용 단어 목록 |
| an embedded wallet | 임베디드 지갑 — 앱 안에 심어져 별도 설치가 필요 없는 지갑 |
| a trusted execution environment (TEE) | 신뢰실행환경 — 격리된 연산 구역. AWS Nitro Enclave 가 한 예 |
| secret sharing | 비밀분산 — 비밀을 조각내 일정 수 이상 모여야 복원되게 하는 기법 |
| a quorum | 의결에 필요한 최소 수 — 지갑에서는 서명이 몇 개 모여야 하는가 |
| custody vs storage | 수탁 대 보관 — 누구의 것인가 대 어디에 있는가. 섞어 쓰면 안 된다 |
| to sponsor a fee | 수수료를 대신 내다 — paymaster 가 하는 일 |
| a blast radius | 폭발 반경 — 하나가 뚫렸을 때 번지는 범위. 보안 문서의 상용어 |
| delegation | 위임 — session key 는 한도가 붙은 위임 |
| to revoke | (권한을) 회수하다 — "revoke a session key mid-flight" |
| to batch calls | 여러 호출을 묶다 — 실패하면 전체가 되돌아가는 것이 atomic |
| to revert | (트랜잭션이) 되돌아가다 — 실패 시 상태가 원래대로 |
| an intent | 인텐트 — 경로가 아니라 원하는 결과를 서명하는 방식 |
| a solver / relayer | 솔버·릴레이어 — 자기 자본으로 결과를 먼저 내주는 주체 |
| an attestation | 어테스테이션, 증명 — Circle 이 CCTP 에서 서명해 주는 것 |
| a challenge period | 이의제기 기간 — 정산이 확정되기 전 되돌릴 수 있는 창 |
| to decline to fill | 체결을 거절하다 — 주문을 받지 않기로 하다 |
| a counterparty | 거래상대방 — 추상화가 늘리는 것이 대개 이것 |
| load-bearing | 하중을 지는 — 그 하나가 빠지면 논증이 무너지는. 비유로 자주 |
| an asymmetry | 비대칭 — 한쪽에게만 되돌릴 수 있는 구조 |
