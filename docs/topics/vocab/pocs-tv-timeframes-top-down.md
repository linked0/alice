| Expression | 뜻 · 쓰이는 자리 |
|---|---|
| timeframe | 타임프레임(캔들 하나가 나타내는 시간 단위) · 이 항목 전체의 핵심어. "switching it does not just zoom the same picture" |
| top-down analysis | 탑다운 분석(상위 타임프레임부터 읽어 내려가는 방식) · 제목과 요약의 핵심 개념. "Top-down analysis is the discipline of reading the higher timeframe first" |
| bias | 방향성, 편향(롱/숏 중 어느 쪽을 볼지의 기본 입장) · 추세 타임프레임이 정하는 것. "set a bias" |
| HTF / LTF | Higher Timeframe / Lower Timeframe(상위/하위 타임프레임 줄임말) · 정렬·충돌을 설명할 때 쓰는 관용 약어. "the higher timeframe generally overrides" |
| trend timeframe | 추세 타임프레임(가장 상위, 방향성 결정) · 세 타임프레임 중 하나. "Trend timeframe (highest): sets the bias" |
| setup timeframe | 셋업 타임프레임(패턴·레벨이 형성되는 중간 단계) · 세 타임프레임 중 하나. "where the actual chart pattern... forms" |
| trigger timeframe | 트리거 타임프레임(진입이 실제로 발동되는 최하위) · 세 타임프레임 중 하나. "where the entry candle actually fires" |
| triple screen | 트리플 스크린(Alexander Elder가 제시한 세-타임프레임 트레이딩 기법) · 세 타임프레임 규칙의 고전적 출처. "close to what Alexander Elder called the triple screen approach" |
| alignment | 정렬(여러 타임프레임의 추세가 같은 방향으로 일치함) · 고승률 경험칙의 근거. "the trade has the wind behind it" |
| countertrend | 역추세(상위 추세와 반대 방향의 신호/포지션) · 충돌 시 하위 신호를 다루는 방식. "treat the lower-timeframe signal as countertrend" |
| swing high | 스윙 고점(주변보다 뚜렷하게 높은 국지적 고점) · 레벨의 무게를 설명할 때. "a single clean swing high on the weekly chart" |
| support/resistance touches | 지지/저항의 터치 횟수 · 레벨이 "실재"한다고 볼 근거. "needs at least two touches to count as real" |
| rule of thumb | 경험칙(엄밀한 법칙이 아닌 관행적 기준) · 이 글에서 반복되는 신뢰도 표현. "a rule of thumb for higher-probability entries, not a guarantee" |
| favorites bar | 즐겨찾기 바(자주 쓰는 타임프레임을 별표해 고정하는 TradingView UI) · On TradingView 절. "open the dropdown, hover a timeframe, and click the star icon" |
| multi-chart layout | 멀티 차트 레이아웃(한 화면에 여러 차트를 배치하는 기능, 유료 전용) · 무료 플랜 제약을 설명. "require a paid plan" |
| sync (symbol/crosshair) | 동기화(여러 차트의 심볼·크로스헤어를 색 그룹으로 맞춤) · 멀티 차트에서의 기능. "sync their symbol and crosshair" |
| log scale / linear scale | 로그 스케일 / 선형 스케일(가격 축 표시 방식) · 장기 차트에서의 선택 기준. "log scale is the standard choice" |
| aggregation | 집계(더 긴 시간의 가격 움직임을 캔들 하나로 압축) · 타임프레임마다 다른 이야기가 나오는 이유. "each timeframe aggregates a different amount of noise" |
