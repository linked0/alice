| Expression | 뜻 · 쓰이는 자리 |
|---|---|
| wire (n., metaphor) | 회로, 경로 (비유) · 하나의 사건이 자산 가격에 영향을 주는 인과 경로를 전선에 비유할 때. "arrives on two wires" |
| half the wiring | 회로의 절반, 절반짜리 설명 · 통념이 전체 메커니즘의 일부만 설명할 때. "is half the wiring" |
| punish (metaphor) | (금리 등이 자산을) 불리하게 만들다, 벌주듯 깎아내리다 · 금리 상승이 특정 자산에 불리하게 작용할 때. "higher real rates punish the zero-yield asset" |
| zero-yield asset | 무이자(수익 없는) 자산 · 이자·배당이 없어 실질금리에 취약한 자산을 가리킬 때. "trading as a zero-yield duration asset" |
| saturate | 포화되다, 한계까지 차다 · 한 경로(채널)가 영향력을 다 써버려 다른 경로가 우세해질 때. "purely because a different wire saturates" |
| tape (n.) | 시세, 그날의 거래 기록 · 특정 시점의 시장 움직임 전체를 가리킬 때. "Today's tape (oil up 4%)" |
| bid (v.) | 매수세가 붙다, 사자 주문이 들어오다 · 안전자산에 수요가 몰릴 때. "gold gets bid again" |
| mean-revert | 평균으로 회귀하다 · 급등락한 가격이 원래 수준으로 돌아올 때. "Mean-revert" |
| give back the move | 상승분(하락분)을 반납하다, 되돌리다 · 가격이 움직인 만큼 다시 원위치로 갈 때. "oil gives back the move" |
