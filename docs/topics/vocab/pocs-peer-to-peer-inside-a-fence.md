| Expression | 뜻 · 쓰이는 자리 |
|---|---|
| a model portfolio | 모델 포트폴리오 — 자산 배분 설계안. 펀드가 아니라 **레시피** |
| asset allocation | 자산 배분 — 어떤 자산군을 어떤 비중으로 |
| a multi-asset strategy | 멀티에셋 전략 — 여러 자산군을 함께 담는 전략 |
| to rebalance | 리밸런싱하다 — 비중이 밴드를 벗어나면 되돌리는 것 |
| a drift band | 허용 이탈 구간 — 리밸런싱 방아쇠가 되는 폭 |
| the trigger vs the execution | 방아쇠 대 집행 — "프로그램적"이 말하는 것과 말하지 않는 것 |
| slippage | 슬리피지 — 의도한 가격과 체결 가격의 차이 |
| an authorised participant | 지정참가자 — ETF에서 설정·환매를 담당하는 기관 |
| peer-to-peer transferable | P2P로 이전 가능한 — 무기명 증권처럼 들리는 표현 |
| eligible investors | 적격 투자자 — 자격 요건을 충족한 투자자만 |
| permitted jurisdictions | 허용된 관할 — 판매가 가능한 국가·지역 |
| a permissioned token | 허가형 토큰 — 보유·이전에 자격 확인이 걸린 토큰 |
| an allowlist | 허용 목록 — 이전이 가능한 주소의 집합 |
| a transfer hook | 전송 훅 — 이전 때마다 실행되는 검사 로직 |
| a bearer instrument | 무기명 증권 — 가진 사람이 곧 권리자인 것 |
| composability | 조합성 — 다른 프로토콜과 맞물려 쓰일 수 있는 성질 |
| bounded composability | 제한된 조합성 — 이 카드가 붙인 정확한 이름 |
| look-through fees | 기초자산까지 들여다본 합산 수수료 |
| redemption mechanics | 상환 구조 — 누구에게, 무엇으로, 며칠 통지로 |
| circulating vs available | 유통 대 가용 — #73이 890 대 1로 가른 구분 |
| a listing vs a product | 상장 대 제품 — 1,300개 선반과 안내판 달린 통로의 차이 |
| the recipe vs the counterparty | 레시피 대 거래 상대방 — 실패를 누가 체감하는가 |
| issuer marketing | 발행사 마케팅 — 보도가 아니라는 표시 |
