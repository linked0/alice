| Expression | 뜻 · 쓰이는 자리 |
|---|---|
| **a leveraged balance sheet that rents itself out** | 자기를 빌려주는 레버리지 밸런스시트 — 은행을 한 문장으로 |
| **balance-sheet-intensive** | 밸런스시트 집약적. 자본을 많이 묶는 사업 |
| **collateral / haircut** | 담보 / 헤어컷(담보 평가 시 깎는 비율) |
| **repo** (repurchase agreement) | 환매조건부채권. 은행의 주된 단기 조달 수단 |
| **HQLA** | 고유동성자산. 규제 완충자본, 대부분 국채 |
| **duration and funding mismatch** | 듀레이션·조달 불일치 — SVB를 죽인 것 |
| **held-to-maturity (HTM)** | 만기보유. 평가손이 자본에 반영되지 않는 분류 |
| **mark to market** | 시가평가 |
| **prime brokerage** | 프라임 브로커리지 — 담보 잡고 빌려주는 일에 다른 모자를 씌운 것 |
| **debt is continuous, equity is episodic** | 부채는 상시, 주식은 이벤트 |
| **a lagging indicator** | 후행 지표 |
| **date-stamp a claim** | 주장에 날짜를 찍다 |
| **it expired** | (주장·근거가) 만료됐다 |
| **cash the cheque** | 수표를 현금화하다 — 앞에서 한 약속을 실제로 뒷받침하다 |
