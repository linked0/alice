| Expression | 뜻 · 쓰이는 자리 |
|---|---|
| credit (verb) | (계좌에) 입금 처리하다 · 예치금을 반영할 때. "enough to credit a deposit" |
| eat (a cost) | (손실을) 떠안다 · 리스크를 누가 부담하는지 물을 때. "the exact failure it accepts... and who eats it" |
| gated on | ~에 달려 있다(그것이 있어야 진행됨) · 도입이 다른 요소에 막혀 있을 때. "FCR adoption is gated on the RPC providers shipping it" |
| wait out | (끝날 때까지) 버티며 기다리다 · 챌린지 기간을 그냥 견뎌야 할 때. "wait out the window" |
| residual risk | 남아있는 잔여 위험 · 완전히 제거되지 않은 위험을 값매길 때. "price the residual reorg risk" |
| tail risk | 꼬리 위험(발생 확률은 낮지만 손실이 큰 위험) · 시간을 단축하는 대가로 감수하는 위험. "manage the tail risk" |
| conflate | (서로 다른 것을) 혼동해서 하나로 묶다 · 두 가지 다른 문제를 같은 것으로 취급할 때. "Conflating the two is how roadmaps promise" |
| inert | 작동하지 않는, 무력한 · 프로토콜은 준비됐지만 실제로 안 쓰이는 상태. "the fast rule is inert until those providers ship it" |
| trending lower | 점차 낮아지는 추세인 · 수치가 계속 감소하고 있을 때. "block time 12s → 10s, trending lower" |
| structural, not an implementation gap | 구현의 흠이 아니라 설계상 근본적인 문제다 · 근본 원인을 짚을 때. "That asymmetry is structural, not an implementation gap" |
