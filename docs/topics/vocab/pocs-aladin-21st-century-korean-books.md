| Expression | 뜻 · 쓰이는 자리 |
|---|---|
| **an imported canon vs. a home-grown one** | 수입된 정전 대 자생한 정전 |
| **the comparison comes free** | 비교가 공짜로 생긴다 (따로 품을 들이지 않아도) |
| **a signed recommendation** | 이름이 붙은 추천. 익명 순위와 대비할 때 |
| **you cannot interrogate a rank** | 순위에는 되물을 수 없다. interrogate = 따져 묻다 |
| **testimony travels, formal experiment does not** | 증언은 국경을 넘고 형식 실험은 못 넘는다 |
| **an export flagship** | 수출 대표작 |
| **domestic canon** | 내수용 정전, 자국 정전 |
| **skew** | 쏠림. a skew toward ~ = ~쪽으로의 쏠림 |
| **the sample, not the subject** | 대상이 아니라 표본 — 편향의 출처를 지목할 때 |
| **mistake a skew for the zeitgeist** | 쏠림을 시대정신으로 착각하다 |
| **a caveat** | 유보, 단서 |
| **neither hedges on it** | 어느 쪽도 유보를 달지 않는다 |
