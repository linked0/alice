| Expression | 뜻 · 쓰이는 자리 |
|---|---|
| a playbook | 정해진 수순·전략집 — "run the playbook backwards" |
| a workaround | 우회로 — 문제를 못 고치고 피해 가는 방법 |
| distribution | 유통망·배포력 — 제품을 사람들 앞에 놓을 수 있는 능력. 스타트업 논의의 핵심어 |
| mercenary capital | 용병 자본 — 수익률만 보고 왔다 떠나는 자금 |
| user acquisition | 사용자 획득 — 마케팅 용어. "the cheapest user acquisition ever invented" |
| to bootstrap | 맨바닥에서 시작해 굴리다 — 유동성·생태계에 자주 |
| a catalyst | 촉매 — 성장을 촉발한 사건 |
| a float | 유통 물량 — 실제로 시장에 돌아다니는 수량 |
| an authorised participant | 인가 참가자 — ETF·토큰화 자산에서 발행·환매를 맡는 지정 기관 |
| to corner a market | 매점하다 — 유통 물량을 장악해 가격을 지배하다 |
| structurally cornerable | 구조적으로 매점 가능한 — 설계 자체가 그 여지를 남긴 |
| a premium | 프리미엄 — 기준가 대비 웃돈. "the premium was gone within the hour" |
| to print (a price) | (가격을) 찍다 — 실제로 체결된 값을 말할 때. 트레이딩 구어 |
| a mania | 광풍 — 투기 국면 |
| sticky liquidity | 남아 있는 유동성 — 떠나지 않는. 반대는 hot money |
| a precondition | 전제 조건 — 없으면 나머지가 성립하지 않는 것 |
| to compensate for | ~를 벌충하다 — "the playbook was compensating for no distribution" |
| a consequence, not an abuse | 오용이 아니라 귀결 — 설계 비판을 정확히 겨눌 때 |
| to be settled | (논쟁이) 정리되다 — "whether the growth is real is settled" |
| whose growth it is | 누구의 성장인가 — 가치 귀속을 묻는 관용적 표현 |
