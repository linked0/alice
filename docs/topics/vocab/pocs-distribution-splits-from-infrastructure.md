| Expression | 뜻 · 쓰이는 자리 |
|---|---|
| spin off | 분사시키다, 별도 회사로 떼어내다 · 사업부를 독립 회사로 분리할 때. "spins its protocols... into a separate company" |
| quietly steering | 티 안 나게 유도하는 · 이해상충으로 은근히 특정 방향으로 몰아가는 것. "quietly steering users into infrastructure it owns" |
| credibly neutral | 믿을 만하게 중립적인 · 이해관계가 없어 보여야 신뢰받는 상황을 말할 때. "credibly neutral — not quietly steering users" |
| captured value | (이해상충으로) 포획된 가치 · 중립적이어야 할 위치가 특정 이익으로 흡수된 가치. "you've found captured value" |
| favor the house | 자기 쪽(운영사)에 유리하게 하다 · 플랫폼이 스스로에게 이득이 되게 설계할 때. "happens to favor the house" |
| invites the obvious discount | 당연한 평가절하를 자초하다 · 편향이 보이면 시장이 알아서 신뢰를 깎는다는 의미. "invites the obvious discount" |
| route around | (문제 있는 지점을) 우회하다 · 사용자·시스템이 편향된 기본값을 피해갈 때. "users and integrators route around a biased default" |
| compounds faster | 더 빠르게 누적 성장하다 · 복리처럼 가치가 쌓이는 속도를 말할 때. "compounds faster as pure distribution" |
| pricing neutrality | 중립성에 값을 매기다(대가를 치르고 중립을 산다) · 분사 같은 결정의 경제적 의미를 설명할 때. "it is pricing neutrality" |
| a funnel | (이익을 몰아주는) 깔때기, 유입 통로 · 사용자를 특정 자산으로 유도하는 구조를 비유할 때. "a captured one does as a Linea funnel" |
