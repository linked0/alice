why: **The same is true of X** carries a judgement you already made over to a second thing, without saying it twice: "the music is dull, and the same is true of the acting." Use "of" for the thing being judged; "the same is true for us" means it also applies to us, which is a different claim. "Dull and uninspiring" is a standard reviewer's pair — boring, and it stirs nothing.

## Techniques
1. **평가를 두 번째 대상으로 옮길 때 "and the same is true of ~".** 반복 없이 두 항목을 같은 평가로 묶는다. "the same is true of the voice-over."
2. **비판은 "무엇이 문제인지"까지 한 줄로 이어 준다.** "Both are safe, and safe is the problem" — 같은 단어를 되받아 요점을 만든다.
