# 84 · Line — There's only so far you can go with nightclubs.
title_ko: There's only so far you can go with nightclubs. — 나이트클럽만으로는 갈 수 있는 데 한계가 있어
situation: Over drinks, Yusuf, a founder friend, says his consulting shop doubled revenue again and he plans to hire ten more contractors. Jay thinks the model has a ceiling and wants to say so without dismissing what Yusuf has built.
situation_ko: 술자리에서 창업자 친구 Yusuf가 자기 컨설팅 회사 매출이 또 두 배가 됐고 내년에 계약직 열 명을 더 뽑을 계획이라고 말한다. Jay는 그 모델에 천장이 있다고 보고, Yusuf가 쌓아 온 것을 깎아내리지 않으면서 그 말을 하고 싶다.
why: **Only so far** marks a limit, not time: "you can only go so far with X" means X takes you to a point and no further. The trap: "so far" alone means "up to now"; the "only" flips it. The pattern is productive — talent, hard work, or money "can only take you so far" — and it is softer than "that won't work" because it grants real progress before naming the ceiling.
why_ko: **Only so far**는 시간이 아니라 한계를 표시한다. "you can only go so far with X"는 X로는 어느 지점까지만 가고 그 이상은 못 간다는 뜻이다. 함정은 "so far" 단독으로는 "지금까지"라는 것이고, "only"가 뜻을 바꾼다. 이 패턴은 생산적이다. 재능, 노력, 돈, 좋은 데이터 없는 AI가 "can only take you so far". "that won't work"보다 부드럽다. 실제 진전을 인정한 뒤에 천장을 말하기 때문이다.

## Dialogue
Yusuf: Revenue doubled again. I'm thinking ten more contractors next year.
> 매출이 또 두 배야. 내년에 계약직 열 명 더 뽑을까 생각 중이야.
Jay: You can only go so far with contractors, though. At some point the margin is your own hours, and those don't scale.
> 그래도 계약직만으로는 갈 수 있는 데 한계가 있어. 어느 순간 마진이 네 시간이 되는데, 그건 안 늘어나잖아.
Yusuf: "So far" as in "up to now"?
> "So far"가 "지금까지"라는 뜻이야?
Jay: No — "only so far" means there's a ceiling. Hard work can only take you so far; after that you need a product.
> 아니. "only so far"는 천장이 있다는 뜻이야. 노력으로는 어느 정도까지만 가고, 그 다음엔 제품이 필요해.
Yusuf: So you're not saying stop, just that the model tops out.
> 그러니까 멈추라는 게 아니라 모델이 한계에 닿는다는 거네.
Jay: Exactly. It got you here, and that's real. It just won't get you to the next number.
> 맞아. 여기까지 데려온 건 진짜야. 다만 다음 숫자까지는 못 가.

## Techniques
1. **한계를 말하기 전에 성과를 인정한다.** "It got you here, and that's real. It just won't get you to the next number." — "only so far"는 진전을 부정하지 않고 천장을 짚는 표현이라 이 순서가 맞다.
2. **"so far"와 "only so far"의 차이를 짧게 바로잡는다.** "No — 'only so far' means there's a ceiling." — 상대의 오해를 예시 한 줄("Hard work can only take you so far")로 고친다.

## Expressions
| Expression | 뜻 · 쓰이는 자리 |
|---|---|
| you can only go so far with X | X만으로는 한계가 있다 — 사업 모델·방법의 천장을 말할 때. "You can only go so far with contractors" |
| X can only take you so far | X로는 어느 정도까지만 간다 — 재능·노력·돈에 두루 쓰는 틀. "Hard work can only take you so far" |
| top out | 한계에 닿다, 더 안 오르다 — 성장이 멈추는 지점. "the model tops out" |
| those don't scale | 그건 규모가 안 늘어난다 — 시간·사람에 묶인 마진을 말할 때 |
