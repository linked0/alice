title_ko: It's not a stretch to imagine something like this happening. — 이런 일이 벌어진다고 상상하는 게 과장은 아니다
situation: In a security review before launch, Jay argues that an admin token with no expiry could end up in a customer's screenshot on a public forum. A teammate calls the scenario far-fetched, and Jay has to show that it is ordinary, not dramatic.
situation_ko: 출시 전 보안 리뷰에서 Jay는 만료 시간이 없는 관리자 토큰이 고객이 공개 포럼에 올린 스크린샷에 그대로 찍혀 나갈 수 있다고 주장한다. 동료는 너무 나간 시나리오라고 하고, Jay는 그것이 극적인 상상이 아니라 흔한 일임을 보여야 한다.
why: **It's not a stretch to imagine something like this happening** says the scenario needs no exaggeration to be believable. "A stretch" is a claim you have to pull out of shape to make it fit, so the negative form is a modest claim: not certain, just plausible. The move is defensive — you use it when somebody has called your worry unrealistic. Say "it's a stretch" about their idea only if you are ready to argue; it politely means "that one is far-fetched".
why_ko: **It's not a stretch to imagine something like this happening**은 그 시나리오가 억지로 늘리지 않아도 충분히 있을 법하다는 뜻이다. a stretch는 억지로 잡아 늘여야 들어맞는 주장을 가리키므로, 부정형은 겸손한 주장이 된다. 확실하다는 게 아니라 충분히 가능하다는 정도다. 상대가 내 걱정을 비현실적이라고 했을 때 쓰는 방어적 표현이다. 반대로 상대의 생각에 "it's a stretch"라고 하면 정중하지만 "그건 억지다"라는 뜻이니 반박할 준비가 되었을 때만 쓴다.

## Dialogue
Yusuf: A support engineer pasting a live admin token into a public forum? That feels like a movie plot.
> 지원 엔지니어가 살아 있는 관리자 토큰을 공개 포럼에 붙여 넣는다고? 영화 같은 얘기인데.
Jay: It's not a stretch to imagine something like this happening. Two vendors we use had exactly that incident last year.
> 이런 일이 일어난다고 상상하는 게 과장은 아니야. 우리가 쓰는 벤더 두 곳이 작년에 딱 그 사고를 겪었어.
Yusuf: Fair. What would you change?
> 인정. 뭘 바꾸면 될까?
Jay: Expire the token in an hour. If the worst case is boring to prevent, we shouldn't need a debate about how likely it is.
> 토큰을 1시간 만에 만료시키자. 최악의 경우를 막는 비용이 시시할 정도면, 발생 확률을 놓고 논쟁할 필요도 없어.

## Techniques
1. **"과장 아니다"로 시작하고 곧바로 사례를 댄다.** "It's not a stretch… Two vendors we use had exactly that incident" — 겸손한 주장 뒤에 사실을 붙이면 설득력이 생긴다.
2. **확률 논쟁을 비용 논쟁으로 바꾼다.** "If the worst case is boring to prevent, we shouldn't need a debate about how likely it is"는 보안 리뷰에서 자주 쓰는 전환이다.
