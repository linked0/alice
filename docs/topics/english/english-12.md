# 12 · Planning — What's the number?
title_ko: 숫자가 뭔가?
situation: Sun-woo says the Chains page "should take a few days." Jay needs a number that can be wrong, not a phrase that can't, and a scope cut if the number is too big.
situation_ko: 선우가 Chains 페이지는 "며칠쯤"이라고 말한다. Jay는 틀릴 수 없는 표현이 아니라 틀릴 수 있는 숫자가 필요하고, 숫자가 크면 범위를 잘라야 한다.
why: Estimation English: how to ask for a commitment without pressure, and how to trade scope for a date instead of asking someone to work faster.
why_ko: 견적 영어. 압박 없이 약속을 요구하는 법, 그리고 더 빨리 하라고 말하는 대신 범위와 날짜를 교환하는 법.

## Dialogue
Sun-woo: The Chains page should take a few days.
> Chains 페이지는 며칠 정도 걸릴 거예요.
Jay: Give me a number I can be wrong about. Three days? Five?
> 제가 틀릴 수 있는 숫자를 주세요. 3일? 5일?
Sun-woo: Five, if the Sepolia RPC in the cloud is sorted. Three if I can ignore it.
> 클라우드의 Sepolia RPC가 정리되면 5일. 무시할 수 있으면 3일이요.
Jay: That's useful, because it tells me where the risk is. What does "sorted" mean, concretely?
> 그게 유용해요. 리스크가 어디 있는지 말해주니까요. "정리된다"는 게 구체적으로 뭐죠?
Sun-woo: Someone decides whether to reuse the secret or add a public fallback.
> 시크릿을 재사용할지 공개 폴백을 추가할지 누군가 결정하는 거요.
Jay: Then I decide now: public fallback when the secret is unset. That takes the question off your plate. Does five become four?
> 그럼 지금 결정할게요. 시크릿이 없으면 공개 폴백. 그 질문은 당신 접시에서 내려놓죠. 5일이 4일이 되나요?
Sun-woo: Four, with the capability matrix as a static table.
> 4일이요. capability matrix는 정적 표로 하면요.
Jay: Static is fine for the first cut. Ship four, and put "matrix from config" in the follow-ups so it isn't forgotten.
> 첫 버전은 정적이면 돼요. 4일로 내고, "설정에서 매트릭스 생성"은 후속 목록에 넣어서 잊히지 않게 해요.

## Techniques
1. **틀릴 수 있는 숫자를 요구한다.** "Give me a number I can be wrong about." "며칠"은 책임을 피하는 표현이고, 숫자는 계획이 된다.
2. **조건부 견적을 리스크 지도로 읽는다.** "it tells me where the risk is" 두 숫자의 차이가 곧 불확실성의 위치다.
3. **결정으로 시간을 산다.** "I decide now… Does five become four?" 압박 대신 미결 사항을 제거해 견적을 줄인다.

## Expressions
| a few days | 며칠 |
| a number I can be wrong about | 내가 틀릴 수 있는 숫자 |
| if … is sorted | …이 정리되면 |
| where the risk is | 리스크가 어디 있는지 |
| concretely | 구체적으로 |
| take it off your plate | 당신의 일에서 내려놓다 |
| does five become four? | 5가 4가 되나? |
| the first cut | 첫 버전 |
| ship four | 4일 안에 내다 |
| put it in the follow-ups | 후속 목록에 넣다 |
