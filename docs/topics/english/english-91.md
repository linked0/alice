# 91 · Line — Like I'd even be caught dead touching her.
title_ko: Like I'd even be caught dead touching her. — 내가 죽어도 저 여자한테 손이나 대겠냐 (wouldn't be caught dead; Like = As if)
situation: Sam suggests extending the old jQuery admin panel for the new dashboard. Jay refuses with the "caught dead" pattern aimed at a tool, then explains the structure and where it turns into an insult.
situation_ko: Sam이 새 대시보드를 오래된 jQuery 관리자 패널을 확장해서 만들자고 제안한다. Jay는 도구를 겨냥한 "caught dead" 패턴으로 거절한 뒤, 그 구조와 어디서부터 모욕이 되는지 설명한다.
why: **Wouldn't be caught dead doing X** means you would never do X and would hate to be seen doing it ("I wouldn't be caught dead wearing that."). **Like…** at the front is the spoken form of "As if…", so the line is a sarcastic, elliptical As-if sentence. Aimed at a tool or a fashion it is a joke; aimed at a person, as in the drama, it is strong contempt, so Jay should keep it for things.

## Dialogue
Sam: The old admin panel still runs on jQuery. Could you just extend it for the dashboard?
> 옛날 관리자 패널이 아직 jQuery로 돌아가잖아. 새 대시보드는 그냥 그거 확장하면 안 돼?
Jay: Like I'd even be caught dead shipping new jQuery in 2026. I'll build it in the React app and link to it from the panel.
> 내가 2026년에 새 jQuery 코드를 내보낼 리가 있겠어. React 앱에 만들고 패널에서 링크로 걸게.
Sam: "Caught dead" — you'd rather die?
> "Caught dead"라니, 차라리 죽겠다는 거야?
Jay: More like "I'd never, and I'd be embarrassed to be seen doing it." And "Like…" at the front is spoken "As if…".
> "절대 안 하고, 하는 모습을 보이는 것도 창피하다"에 가까워. 앞의 "Like…"는 그냥 "As if…"의 구어체고.
Sam: So "as if I'd ever ship jQuery" is the same thing.
> 그럼 "as if I'd ever ship jQuery"도 같은 말이네.
Jay: Same thing, a bit tidier. Just don't aim it at a person — then it's an insult, not a joke.
> 같은 말인데 조금 더 정돈된 거지. 다만 사람한테는 겨누지 마. 그러면 농담이 아니라 모욕이야.

## Techniques
1. **강한 거절은 사물에 겨누고 대안을 바로 붙인다.** "Like I'd even be caught dead shipping new jQuery in 2026" — 빈정거림 한 줄 뒤에 실행안이 오면 농담으로 남는다.
2. **구어 구조를 격식형과 짝지어 설명한다.** "'Like…' at the front is spoken 'As if…'" — 상대가 되물을 때 표준형을 알려 주면 두 형태를 다 쓸 수 있다.

## Expressions
| Expression | 뜻 · 쓰이는 자리 |
|---|---|
| wouldn't be caught dead doing X | 죽어도 X는 안 한다 — 사물·패션·도구에는 농담, 사람에게는 모욕. "caught dead shipping new jQuery" |
| Like I'd ever … | 내가 ~할 리가 — "As if I'd ever …"의 구어형 |
| ship | (코드·기능을) 내보내다, 배포하다 — 개발 회화의 기본 동사 |
| aim it at a person | 사람을 겨냥하다 — 표현의 대상을 제한할 때 |
