  • Verex: measure matching-engine and market-maker latency claims under real peak order flow, not a demo trace. The same discipline as reading past a "6G" label — the number that matters only exists as a measurement under load.
  • Bridge: give the lock-and-mint relayer a stated latency-and-reliability budget, with a defined fail-safe on a stalled relay. A demo number under light load says nothing about congested-network behavior.
  • Rabbit: define the session-key/mandate execution control loop's round-trip latency budget and its stall behavior. A user waiting on a signed action is closing a control loop the same way a teleoperator is; specify fail-closed, not frozen, on a dropped step.
