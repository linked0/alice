  • OFA: "솔버 X가 Y%의 확률로 이긴다"는 주장을 믿기 전에 필요한 경매 라운드 수를 Hoeffding 경계로 산정한다. 결과가 유계이기 때문에 이 경계를 쓸 수 있다. 라운드가 같은 솔버나 같은 블록을 공유하면 독립성이 깨지므로 무효로 표시한다.
