  • Token/Bridge: JYVE 유동성이 체인 간 "공유"된다고 주장하기 전에 크로싱 스프레드를 측정한다. 브리지가 공급하는 풀에 이 페이지가 설명하는 여러 크기별 깊이-대-벤치마크 측정을 동일하게 실행해, 실제 시장이 만들어지는지 아니면 인접성뿐인지 확인한다.
  • Devnet: 포크된 풀 대상으로 스프레드/깊이 측정을 재사용 가능한 PoC로 스크립트화한다. 공개 상태와 벤치마크 금리만 있으면 되므로, Jayverse가 등록하는 모든 두 자산 풀에 비용 없이 돌릴 수 있다. Devnet이 "열려" 있고 참조 시장이 닫힌 주말을 포함해 샘플링한다.
  • Number: 온체인 대 벤치마크 스프레드 비율을 반복 읽기 항목으로 추적한다. 다른 지표와 같은 토큰화된 읽기 형태로, 날짜와 라이선스를 붙여 발행한다.
