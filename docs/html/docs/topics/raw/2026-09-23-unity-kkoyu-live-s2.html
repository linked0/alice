10월 20일

진화하는 URP! in Unity 6.6, 6.7, 7 유니티 렌더링 엔진은 URP로 통합될 예정입니다. Unity 6.6, 6.7을 거쳐 완전히 새로워질 Unity 7까지의 그래픽스 로드맵을 소개합니다. 연사자: 박종태, Staff Partner Engineer, Unity

앱스토어 밖에서 수익 창출하는 법: Unity IAP 웹샵 소개 및 구현 Unite Seoul에서 처음 공개한 Unity IAP D2C 커머스, 그 이후의 업데이트를 정리합니다. 웹샵을 구성하고 게임 안에서 플레이어를 스토어로 연결하는 과정을 단계별로 살펴봅니다. 연사자: 김보은 Senior Product Designer, 신평호 Senior Partner Engineer, Unity

지금, Diagnostics(DDF)를 켜야 하는 이유 Unity 6.2 이상으로 시작한 프로젝트는 Diagnostics(DDF)가 기본 활성화되어 있지만, 라이브 서비스 중인 프로젝트는 꺼져 있는 경우가 많습니다. Diagnostics가 왜 지금 켜져 있어야 하는지와 확인 가능한 데이터를 실제 고객 사례와 함께 소개합니다. 연사자: 신평호, Senior Partner Engineer, Unity

10월 21일

AI와 함께하는 유니티 2D 게임 성능 최적화 실전 2D 게임도 성능과 발열 이슈에서 자유롭지 않습니다. AI를 '성능 최적화 파트너'로 활용해 병목 분석, 메모리 관리, 프레임 확보를 해결하는 실전 노하우를 시연합니다. 연사자: 오지현, Senior Advocate, Unity

Physics Core 2D로 새로운 게임경험 제작하기 새롭게 선보이는 물리 2D 시스템, Physics Core 2D를 활용해서 생각하지 못했던 역동적인 장면을 연출해보세요. 대량의 물리 객체를 흩뿌리고 충돌시켜도 거뜬한 성능의 원리와 활용법을 함께 알아봅니다. 연사자: 김재익(Goldmetal), Senior Advocate, Unity

Sentis로 모바일 기반에서 동작하는 런타임 에이전트 구축하기 지난 Unite Seoul에서 공유한 Sentis Skills 모델들을 활용합니다. 온디바이스 환경에서 동작하는 런타임 AI 에이전트의 설계 및 구축 프로세스를 살펴봅니다. 연사자: 김한얼, Senior Partner Engineer, Unity
