    • Standard Transformers rely on self-attention, comparing every token with every other token, which incurs quadratic ($O(N^2)$) compute and memory costs as context lengths expand.

    • Developed by researchers from Carnegie Mellon and Princeton, Mamba replaces the attention mechanism with a selective state-space model that processes sequences linearly ($O(N)$).

    • Enables smaller parameter models (e.g., 3B parameters) to match the accuracy of significantly larger Transformer architectures, drastically reducing cloud deployment costs and unlocking edge execution.
